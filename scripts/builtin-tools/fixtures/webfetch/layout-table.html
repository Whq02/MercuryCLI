Release notes for the 4.2 line

The 4.2 line is the last to run on the classic kernel. Every build in this line carries the long-term patches for the archive reader and the two format changes described below, so an upgrade from 4.1 needs the migration step described in the handbook before the first start.

4.2.3

The archive reader now rejects a truncated index instead of reading past the end of the file; the message names the byte at which the index ended. The configuration loader accepts a trailing comma in every list, matching the documented grammar, and the sample files ship with one so the parser is exercised on every install.

4.2.2

A regression from 4.2.1 made the scheduler skip the first job of a quiet hour when the clock crossed midnight; the fix keeps the job and adds a check that runs on every start. The log line for a skipped job now carries the reason in words rather than a numeric code.

4.2.1

The first maintenance release of the line: six fixes to the exporter, one to the importer's handling of empty fields, and the usual round of translation updates. Nothing in the file formats moved.
