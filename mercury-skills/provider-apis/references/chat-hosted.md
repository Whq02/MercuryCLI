# Hosted provider/account notes

Paths below are relative to `src/services/providers/` (code map 2026-10-26; vendor URLs in `live-sources.md`).

- **OpenRouter** (`openrouter/openrouterCallModel.ts`, `openrouter/openrouterCache.ts`, `openrouter/openrouterRoutingPolicy.ts`, `openrouter/openrouterUsageState.ts`): confirm Responses vs chat before editing; chat sets explicit cache breakpoints only on supported upstreams with catalogue-driven effort; usage reads active-key budgets and inline cost (see `openai-responses.md` for mixed-upstream retry and routing preferences).
- **Hugging Face** (`huggingface/huggingfaceCallModel.ts`, `huggingface/huggingfaceUsageState.ts`): Hub router auth, provider/policy-qualified slug, optional `X-HF-Bill-To` (org/resource group), token ceiling and streamed usage; `whoami` gives identity/plan/rates, not full account spend.
- **Nous Portal** (`nous/nousCallModel.ts`, `nous/nousCatalogue.ts`, `nous/nousOauth.ts`, `nous/nousUsageState.ts`): inference host, qualified slug and catalogue efforts are separate from OAuth subscription credit (**UNRESOLVED** externally: OpenAPI robots-refused).
- **OpenCode Zen** (`zen/zenCallModel.ts`, `zen/zenPins.ts`, `zen/zenResponsesTransport.ts`, `zen/zenUsageState.ts`): per-model chat/Responses routing, session header, preserved Kimi history, Go windows and session spend; newer public `/inference/...` URLs do not authorize migrating `/zen/v1` (**UNRESOLVED** externally).
- **Together** (`together/togetherCallModel.ts`, `together/togetherAccounts.ts`, `together/togetherPins.ts`, `providerUsage.ts`): hybrid reasoning toggle vs effort, streamed usage with flat/nested cache counters, session spend (org billing API is a per-org beta returning 404 without access).
- **Groq** (`groq/groqCallModel.ts`, `groq/groqPins.ts`, `groq/groqUsageState.ts`): model-specific `include_reasoning` vs `reasoning_format`; separate RPD and TPM reset/remaining headers; 400 spend-cap classification is CODE policy.
- **Cerebras** (`cerebras/cerebrasCallModel.ts`, `cerebras/cerebrasPins.ts`, `cerebras/cerebrasUsageState.ts`): cache key, effort and streamed usage; omits max-output to avoid full-ceiling reservation (provider still estimates); tracks retry waits, session spend, and uncached vs total TPM buckets.
- **Fireworks** (`fireworks/fireworksCallModel.ts`, `fireworks/fireworksPins.ts`, `fireworks/fireworksUsageState.ts`): canonical model/router IDs, session affinity, reasoning replay, token ceiling, `minimal`→`low` mapping (CODE policy), and separate prompt, cache-adjusted prompt, uncached-prompt and generated limit headers (distinct from Elastic Burst).
- **Melious** (`melious/meliousCallModel.ts`, `melious/meliousCatalogue.ts`, `melious/meliousUsageState.ts`): send catalogue-supported effort without global folding, retain flavor, require `[DONE]`, preserve railguard finish reasons and in-stream errors, retry `billing_hold_creation_failed` only before output (never arbitrary quota errors), and keep EUR `billing_cost` + `environment_impact` distinct from USD cost fields.
- **OrcaRouter** (`orcarouter/orcarouterCallModel.ts`, `orcarouter/orcarouterCatalogue.ts`, `orcarouter/orcarouterUsageState.ts`): opt-in `usage.cost_usd` (absent cost = unknown, never free), session affinity, fallback-model observations and dashboard usage/subscription readers (**UNRESOLVED** private JSON/headers).
