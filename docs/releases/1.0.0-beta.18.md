# 1.0.0-beta.18 — queued

**State:** queued behind 1.0.0-beta.17. This release focuses on reliability
by running Mercury on every supported provider, on a machine that can handle
the load. Each model works on its own sign-in and account handling in a
dedicated sandbox, and all of that work is treated as untrusted and
verified. That tests multi-account use on complex work in Mercury's own
codebase, with fixes addressing the root causes. The items queued for it are
listed on the 1.0.0-beta.17 page under "Queued for 1.0.0-beta.18".

1.0.0-beta.19 will preserve the live runner across daemon restarts.
1.0.0-beta.20 will add image generation as a tool, or finish the rest of the
queue first. 1.0.0-beta.30 is the release candidate for leaving beta. Grok
and Muse will be added where they fit; Perplexity follows after beta.
