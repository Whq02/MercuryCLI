# 1.0.4 — published 2026-11-03

**State:** published 2026-11-03 at
github.com/Whq02/MercuryCLI/releases/tag/v1.0.4, tag on commit b94fa524.
Mercury CLI 1.0.4 takes the limits off the crew board and makes the crew's
tools dependable. Every post now reaches every crewmate whole, a crewmate
keeps its board tool for its whole run, and tools from an MCP server added
during a session are offered to the model at once. The release also keeps the
working row's clock and token counter through permission dialogs, gives a
project opened by two spellings of its path one store, one memory and one
workspace, and repairs smaller faults in the Test tool, Eval cells, leases and
the composer.

## What changed

- Changed the crew board to carry every post whole to every crewmate: a post
  reaches every enrolled crewmate, the lead included, at its next turn
  boundary, and a read returns everything new. The swarm limits are gone with
  their settings: /swarm cap and /swarm uncap, the Swarm limits group in
  /config, and the swarm.seatAllowance, swarm.waveAllowance, swarm.postChars,
  swarm.postsPerMinute and swarm.postsPerSeat keys; an older settings file
  still carrying them loads silently, and a board file from an older build
  drops its limit tables when opened.
- Fixed a crewmate on the live crew board posting once or twice and then
  losing its CrewBoard tool for the rest of its run; a crewmate now carries
  the board tool in full from launch or resume, while the lead keeps it on
  demand.
- Fixed the notice that tells the model which tools joined or left: it names
  only real changes (a tool the model already called or found by search is not
  announced again, and the last deferred tool leaving still is), and a resumed
  session's notice follows what that session recorded.
- Fixed tools from an MCP server added during a session not being offered to
  the model until the next session.
- Fixed the working row losing its clock, token count and speed after a
  permission dialog when a prompt had been sent mid-turn; switching views no
  longer needed to bring them back.
- Fixed a project opened by two spellings of its path (a different letter
  case, a symlink, or a case-sensitive disk) getting a second session store,
  memory and workspace; the directory's own identity decides, a store under an
  older spelling is adopted on the first write, and reads never create files.
- Fixed Mercury refusing to start when crew-board.mjs is missing beside
  mercury.mjs; the swarm says what is missing and names the reinstall instead.
- Fixed a crewmate's note appearing in the composer after a sign-in wall; only
  your own unanswered line is handed back.
- Fixed the transcript search not finding words from crew-board posts.
- Fixed a crewmate's completion report listing checks that other crewmates
  ran; it reports only its own.
- Fixed an Eval cell failing to read a nested tool's large result once the
  transcript kept only its preview; the cell receives the whole value and the
  display names the saved file.
- Fixed a failed JS Eval cell printing its error headline twice.
- Fixed the Test tool failing to load a unittest file under a hidden or dotted
  folder, such as .mercury or alpha.beta; the module path now starts below
  that folder.
- Fixed lease calls on Windows paying about half a second per holder; holders
  are checked in one batch and the answer is kept for three seconds, and a
  stale answer can keep a refusal but never take a live lease.
- Fixed an uncaught disk error when the crew-board file disappears under a
  running session; the read reports no change.
