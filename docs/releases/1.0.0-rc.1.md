# 1.0.0-rc.1 — ready for the tag

**State:** ready for the tag. A feature and reliability release. Mercury adds
local image and video generation on Apple Silicon macOS through the bundled
mercury-media extension and /imagesetup, direct Hugging Face GGUF downloads
and Bank serving in /localsetup, an Anthropic API key option under /logins,
and ctrl+s s to send a queued line into a waiting turn. The TypeScript and
Python SDKs gain timeouts and typed errors, file leases release in bulk and
when a crewmate ends, file anchors and tool rosters survive restarts and
compactions, and fixes land for Anthropic Console sign-in and account
switching, malformed tool calls, crewmate resume, Gemini stop reasons, HTTP/2
connection blips, Bash working directories, the advisor and the first-run
wizard.

## What changed

- Added the bundled mercury-media extension and /imagesetup for local image
  and video generation on Apple Silicon macOS through stable-diffusion.cpp:
  enable Local media in /config, download the runtime and any of six catalogue
  models (z-image-turbo, flux2-klein-4b, qwen-image-21-turbo, qwen-image-21,
  wan22-ti2v-5b and minimax-h3-fl2va) through SHA-256-verified pulls you can
  pause and resume, set the default image and video models, preview a test
  image, and generate through the image_generate, video_generate and media_*
  MCP tools behind their own permission cards (docs/MEDIA.md)
- Added direct Hugging Face GGUF downloads and Bank serving to /localsetup:
  list a repository's quantisations with their download size and the largest
  context window that fits your memory, pull one with SHA-256 verification and
  resumable downloads, serve it or any Bank model through llama-server on
  127.0.0.1:8080 and select local/<name> (docs/LOCAL-SETUP.md)
- Added an Anthropic API key option (usage-based billing) to /logins →
  Anthropic: paste a key, verified before it is saved, with the workspace ID
  when the key is organisation-scoped
- Added ctrl+s s to send a line queued behind a running turn into that turn
  while it waits inside a tool call: the crewmate or command it was waiting on
  moves to the background and a Sleep ends; the SDKs gain sendNow() and
  send_now() (docs/SESSIONS.md)
- Added twenty thinking verbs to the turn spinner's desert set
- Changed the TypeScript and Python SDKs: connect and prompt timeouts bound
  initialization and the whole turn, broken streams and calls after close()
  raise MercuryConnectionError, malformed notifications raise
  MercuryWireError, and assertCompleted raises MercuryOutcomeError with the
  outcome and the runner's recovery instructions (sdk/README.md,
  sdk-py/README.md)
- Changed project file leases: mcp__mercury__lease_release with no paths
  releases every lease the caller holds, the main session can release one
  crewmate's (agentId) or every holder's (all: true) leases, and a crewmate's
  leases are released when it finishes, fails or is stopped (docs/CREW.md)
- Changed file anchors and tool rosters: Write and whole-file Read(ranges)
  return a file anchor for Edit and ChangeSet, a session resumed on a new
  build replays its tool roster so the prompt cache and signed thinking stay
  intact, MCP tool changes update in place without moving the bound prefix,
  and compaction carries fully loaded tools on every provider
  (docs/CHANGE-TRANSACTIONS.md)
- Changed local media setup so a successful pull turns Local media on in the
  running session, a model installed or set as default mid-session is used by
  the next call, and image_generate and video_generate take the slot default
  when no model is named (docs/MEDIA.md)
- Changed the bundled provider-apis skill to describe the provider APIs as
  Mercury uses them today, each vendor page checked on 2026-10-26
- Changed internal modules to remove unused helpers and dead declarations,
  with no change to behaviour or screen text
- Fixed Anthropic Console sign-in and account switching: sign-in waits for the
  key to be stored, a replaced stored API key is re-read from disk, and
  switching account slots applies to new requests while a turn in flight keeps
  its credential
- Fixed malformed tool calls, queued crewmate messages, Gemini stop reasons
  and stopped-crewmate resume: a tool call with invalid arguments or an
  unknown tool returns a paired error result on every provider, a crewmate
  with queued messages takes its next turn before completing, a Gemini reply
  whose signature arrives after the text keeps the text, and TaskStop followed
  by ResumeCrewmate on Anthropic no longer hangs (docs/AUTOMATION.md)
- Fixed Connection error [ERR_HTTP2_STREAM_ERROR] blips under crewmate fan-out
  and long Gemini streams: API dispatch uses HTTP/1.1 with sixteen connections
  per origin, so one reset stream no longer cuts the others
- Fixed the Crewmates popup: the mouse wheel and PgUp/PgDn scroll the list
  instead of the transcript behind it, a click selects a row and a
  double-click opens it
- Fixed Bash working directories: a leading cd is stripped only when it
  matches the shell's current directory, cwd is kept on every call, and
  verification scoring ignores read-only diagnostics while still flagging
  piped tests whose exit status is lost
- Fixed advisor truncation: every key of a tool call's input is kept when long
  strings are shortened, truncated inputs and results are marked, notes that
  depend on unseen text are suppressed, and crewmate launch receipts name the
  resolved model on every provider
- Fixed Eval's completion() returning no text when a provider places a
  reasoning block after the answer
- Fixed the update channel so a final release tag (v1.0.0) is recognised and
  ordered above every prerelease of its version
- Fixed five crewmate and context faults: a crewmate's auto-compaction touches
  only that crewmate, thinking minted after the twentieth image survives,
  WebFetch with a prompt reads a reply whose thinking precedes the text, a
  resumed crewmate keeps its signed thinking after a main-thread compaction,
  and a Z.AI pause names the reset time the provider states
- Fixed the local media downloader running on the session's environment
  instead of the scrubbed one, and a letter typed with Ctrl or Alt held
  triggering /imagesetup actions
- Fixed an advisor note arriving as /advise off landed being discarded
- Fixed the resumed-session card painting inside the previous turn, the
  first-run wizard's trust step showing two key-hint rows, and Esc at the
  trust step ending setup without a word: it now says "Setup stopped. Run
  mercury again to finish."
- Fixed a running session losing its effort level when you sign in to your
  OpenAI account again: a session set to max keeps sending max, and the
  account's model list is kept rather than refetched
