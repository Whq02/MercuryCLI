# 1.1.0 — ready for the tag

**State:** ready for the tag. Mercury 1.1.0 replaces its core with the Pi one,
for simplicity. Everything should work just like 1.0.12. Beyond that, the
Browser tool can attach to a Chromium browser you started yourself, replies
keep streaming while you resize the window, sessions start faster on Windows,
and crewmate lines show how long a crewmate has been running. Arabic now reads
in the right order in Apple Terminal and iTerm2, and the runs card, the
prompts list, /diff, the crew chat and the workbench open as a box in the
middle of the screen. Session contracts are gone. Updating is recommended for
every install: 1.0.12 keeps two holes that this release closes, a signed
archive whose manifest alone was altered being taken as sound, and on Windows
a file on another drive being read or written with no card. I thank Mario
Zechner for Pi, and Vadym Demedes, Sindre Sorhus and the Ink project.

## What changed

- Added attach to the Browser tool. It connects to a Chromium browser you
  started with a debugging port (this machine only) and lists its tabs.
  Mercury asks once before attaching and once per site before first reading or
  acting there. Close detaches and leaves your browser and tabs open.
  Clicking, typing and taking a screenshot do not bring the browser's window
  to the front.
- Added about 460 verbs and phrases to the spinner.
- Added a title keyword to claim() in the Python SDK.
- Changed the core: it was replaced with the Pi one, for simplicity. Commands,
  tools, sessions and settings work the same as in 1.0.12.
- Changed the runs card, the prompts list, /diff, the crew chat (/swarm) and
  /workbench to open as a box in the middle of the screen in the full layout,
  with the typing box and the side boxes still in view. In a small window (the
  compact layout, below 100×26) the runs card, the crew chat and the workbench
  keep the full-width pane they had in 1.0.12.
- Changed crewmate status lines to show "running for <time>" while active and
  "landed in <time>" once done, across the launch block, the crewmate card and
  the top of the detail window.
- Changed tool calls refused by the crew board, and ones with invalid input,
  to show on one line ("· not posted" or "· invalid input"). The transcript
  view shows the reason.
- Changed ten result lines and notices to be shorter, including "Delivered to
  <name>", "Row not found" and "[image data sent to the model]".
- Changed the USAGE rail when you aren't signed in to show Usage and "not
  signed in — /logins signs in".
- Changed /logins to show only the sign-in rows. The scroll wheel now moves
  the selected row.
- Changed Shift+Tab so switching permission modes doesn't send a notice on its
  own. The model hears about a new mode once on its next turn, and switching
  away and back sends nothing.
- Changed mercury sessions delete and Session Manager's prune to also remove a
  session's crewmate transcripts.
- Changed pasting text whose first line is an unknown /command. It's now
  refused as an unknown command, just like a typed one.
- Changed workspace trust in the home folder so your answer is remembered for
  the home folder alone. Folders inside it still ask.
- Changed language-server diagnostics in a crew. Each crewmate gets
  diagnostics for the files it wrote or opened, and when it finishes, the lead
  only gets diagnostics for files in its own project folder.
- Changed the engines Mercury downloads to Ollama 0.40.18 for Linux and
  Windows hosts and TensorFold 1.3.4. Download sizes in /localsetup now match
  the current model cards.
- Changed Windows session startup to make fewer process reads: each process
  reads its own start once, and the daemon reads the runners it remembers in
  one pass. On the Windows test machine, Continue Last Session after a restart
  was ready in 10.3 s, against 17.3 s on 1.0.12.
- Changed two file-name checks. Pasted text is stored and read back only under
  a 16-character hexadecimal name, and large tool results are written to disk
  only when the call id is a valid file name.
- Changed rm -rf /mnt/c on Windows so it's refused as a drive root, just like
  rm -rf /c.
- Changed the health check's PowerShell script-policy warning so it only shows
  when you start Mercury from PowerShell.
- Changed long PowerShell permission cards to show the command's first and
  last lines with a shorter reason, so the question stays on screen.
- Changed the Browser tool's wording about installed browsers from "never
  driven" to "never launched".
- Changed the ACP README to explain how an editor's file and terminal
  capabilities are used.
- Changed sessions to have no contracts: the /contract command, the Contract
  tool, the Contract row in the schedule form, the contract offer card in
  Session Manager and the contract action on the daemon's socket are gone. Any
  schedule saved with a contract now starts a plain session.
- Changed Session Manager's mirror so that a receipt without a label of its
  own shows its own summary; the "contract:" label is gone.
- Changed the /model picker: the tier at its bottom is gone, and each
  provider's header shows its sign-in.
- Changed crewmate launch lines and the top of the crewmate detail window to
  show no tool count.
- Changed the /logins chooser to show no Provider readiness block.
- Changed the folio heads in editor responses to carry no scopeFold member,
  which was always empty.
- Changed runs under NODE_ENV=test to stream normally instead of failing with
  "Missing VCR fixture": recorded-fixture replay and MERCURY_VCR_RECORD are
  gone, and so is the unused MERCURY_DEMO_VERSION.
- Changed the repository to have no top-level fixtures folder.
- Changed updates to check a downloaded archive before unpacking it. Mercury
  reads the archive's own listing and refuses one whose entries leave the
  unpack folder, that holds links out of it or devices, or that passes 100,000
  entries or 4 GiB; after the unpack it looks at the folder before anything
  else reads it. A download is cut off at 1 GiB. On the test machines an
  update took one to two seconds longer on macOS and Linux and about six on
  Windows.
- Changed what an update says when its archive cannot be read at all: the
  words after "archive extraction failed:" are Mercury's own, such as
  "unexpected end of file".
- Changed the daemon's folder and its files on macOS and Linux to be readable
  by your user alone.
- Changed the refusals to delete a drive root, a home folder or another user's
  folder so that they know more spellings: /cygdrive paths, extended-length
  and FileSystem:: paths, PowerShell's -Recurse:$true, rd /s/q and del /s/f/q,
  character-class globs, and rsync --delete into another user's folder.
- Changed fourteen messages for something that could not be saved to one plain
  sentence each, the model picker's "not saved as your default" among them.
  The path and the error go to the debug log.
- Changed /tensorfold on Windows to mark a starting model that only a Mac can
  run as "Mac only", with one line, "needs · an Apple Silicon Mac". Enter
  starts no download there.
- Changed the Godot debugger tools to accept Godot 4.7 as well as 4.6.
- Changed python_run over the Blender bridge to end with one undo step named
  "Mercury python_run". Blender then shows the file as unsaved, so blend_open
  refuses until you save, and Edit > Undo takes the run back. A run that only
  read is marked too.
- Changed the archive's NOTICES.md to carry the copyright line and the licence
  text of each of the 63 bundled packages.
- Changed the /health flux row to say "the local frame/latency probe" where it
  said telemetry, and three flag descriptions to drop the words telemetry and
  analytics.
- Changed mercury --worktree to hold a repository's own
  workspace.worktree.prepare command until the trust card is answered. The
  command waits for a yes and never runs after a no.
- Changed a new or a resumed session on Windows to wait when another program
  briefly holds the daemon's records file. Held for 1.5 s on the Windows test
  machine, the session started; held for 6 s, it was refused after 3.6 s.
- Changed how Mercury tells the model about a very large change on disk: over
  two or three requests where it told it in one, so the screen keeps drawing
  meanwhile.
- Changed a resumed session on Google to send a tool-search result with the
  line the live session sends with it, so the provider's prompt cache can
  serve the conversation after it.
- Fixed an update or an install taking a signed archive whose manifest alone
  had been altered: such an archive is now refused. 1.0.12 and the releases
  before it keep this hole, so update.
- Fixed Mercury on Windows reading or writing a file on another drive without
  showing its permission card. 1.0.12 keeps this hole, so update.
- Fixed Arabic text in the typing box, in answers while they stream and at
  rest, in tables and after a resize. It reads joined and in order in Apple
  Terminal and in iTerm2 3.7.6 and later, and the cursor block stands where
  the next letter goes. In Windows Terminal an Arabic table keeps its columns
  and its lines; a lam-alef pair is still drawn there as two letters, and the
  console window's own fonts draw Arabic letters as boxes.
- Fixed mercury sessions delete refusing every session. It now deletes a
  parked session that has no live runner, and the session's row leaves Session
  Manager; a session with a live runner is still refused.
- Fixed the PowerShell tool answering "(No output)" for a command that answers
  with objects, such as Get-Location, pwd or Get-Item piped to Select-Object.
- Fixed the Blender bridge add-on failing to enable in Blender with
  "'_RestrictData' object has no attribute 'filepath'", from Preferences and
  from the one-line enable the install prints. It now enables and the bridge
  answers; this was run on Blender 5.3.
- Fixed replies freezing while you drag the window width. They now keep
  streaming, with the longest drag pause down from about 0.3 s to 0.06 s.
- Fixed a blank band left under a long block, like a file diff, after you
  resize the window and bring it back.
- Fixed the screen sitting idle for a few seconds after pressing Enter on a
  new session's first prompt. The working row now shows up right away.
- Fixed a background crewmate's launch line showing "0 tool uses".
- Fixed a crewmate seeing changed lines from files that only another crewmate
  had read when their turns overlapped.
- Fixed del /f /q on Windows being refused with a message about Mercury's own
  runtime.
- Fixed the PowerShell card mistaking a regular expression for a network path,
  and the Bash card doing the same for escapes inside a quoted sed, grep, rg
  or awk pattern.
- Fixed Mercury missing updated tools when an MCP server changes them
  mid-session. The next request now sends the new tool list.
- Fixed a Qwen model not included in your plan marking the key as refused.
- Fixed a stray 404 on a Google sign-in session ending the turn after the
  model answered. The request is now retried.
- Fixed mercury sessions list sorting sessions with the same file timestamp
  differently on different platforms.
- Fixed the Boot face's prune card at 120×40 pushing No and Yes below the
  pane, and fixed detail panes breaking long lines mid-word.
- Fixed pressing Enter in the Crew view doing nothing on a crewmate that had
  already landed.
- Fixed a turn's receipt counting resumed history as added context after you
  resume a session.
- Fixed the compaction receipt overstating the new size by about 2.8k tokens.
- Fixed the Extensions row in /health showing ok even when extensions list
  reports a broken extension.
- Fixed the PowerShell tool on machines without PowerShell so it says
  PowerShell is unavailable.
- Fixed accepting a folder from path suggestions so completion continues
  inside that folder.
- Fixed a compaction summary with $ patterns getting altered when put back.
- Fixed Mercury asking about a sed long option as if it were a path.
- Fixed words inside a quoted git commit message triggering a
  destructive-command note.
- Fixed lists with no focused row not showing which row your keys act on.
- Fixed a failed shell snapshot leaving no error line.
- Fixed Anthropic request costs double-counting a second message delta.
- Fixed the Other row's box being misaligned in letter-labelled multi-selects.
- Fixed cargo rerun-failed to run every failed test by exact name, Go subtest
  selection to keep the exact test, and the TypeScript language service to
  list refactors for a refactor.* kind.
- Fixed /clear on Windows saying the cleared session couldn't be parked when
  another program briefly held the daemon's records file. Saving now retries
  for about three seconds, and the daemon picks up any refused park again.
- Fixed the spelling of colours in the first-run theme step.
