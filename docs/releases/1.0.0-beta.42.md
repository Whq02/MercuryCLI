# 1.0.0-beta.42 — ready for the tag

**State:** ready for the tag. A feature and security release. In /llmhost,
Which model? searches the 78 shipped recipes across 32 models alongside any
public Hugging Face text-generation model by name (labeled found on Hugging
Face · not booted by Mercury), checks GGUF shard headers and safetensors
quantisation methods against the engines before anything is rented, and lists
in-stock GPU rentals from Runpod, Vast.ai, Lambda and Hugging Face Inference
Endpoints side by side with per-vendor verification stamps, Vast.ai
datacenter, community host or host tags, in-place vendor key controls, and one
stock watch across all connected providers. A new Bank screen in /llmhost
downloads and hash-verifies your own local copy of a model's weights, copies a
bank (including config and tokenizer files) to a second drive or uploads it on
first boot to Vast.ai and Lambda with k keep safe, and mirrors shipped,
derived or private recipes onto Runpod fast-load volumes or machine-bound
Vast.ai volumes using the cheapest fitting instance in stock. The shipped GGUF
recipes carry their vision projectors on a rebuilt prebuilt llama.cpp image
(163 architectures), the Computer tool takes lighter captures and reads macOS
terminal windows as text, the Debug tool evaluates in a named context with
expandable variable references and tree-wide conditional function breakpoints,
and Edit and Write report new syntax errors in TypeScript, Python, Rust, Go
and C without a language server. The bundled Node runtime is updated to
24.22.1 (CVE-2026-111497), the CLI and SDK licence split is stated in plain
language across LICENSE.md and the READMEs, and SGLang default thinking,
/llmhost mouse-wheel scrolling, post-ready engine crash reporting, self-hosted
turn, session and SDK parity, Windows batch invocation and crewmate resume
defects are fixed.

## What changed

- Added live model search and pre-rental engine loadability checks to /llmhost
  on Which model?: typing filters the 78 shipped recipes immediately and
  queries Hugging Face after 3 characters for public text-generation models
  sorted by downloads (labeled found on Hugging Face · not booted by Mercury,
  with parameters, format, download count, licence, gated or private status
  and the unverified stamp), and selecting a Hugging Face model reads its
  paginated file tree and config.json (using your /logins huggingface token or
  HF_TOKEN for gated models), checks GGUF shard headers by HTTP range requests
  against the 163 architectures and 314 tensor names of the prebuilt llama.cpp
  engine (assets/host/llamacpp-engine.json at llama.cpp 184f6536) and
  safetensors quant_method values against vLLM's supported quantisations
  (refusing unknown GGUF architectures or tensor families, EXL2/EXL3 and
  unsupported quantisations before any rental or watch), and derives a
  llama.cpp or vLLM recipe on the spot with the smallest fitting GPU shape and
  live prices (docs/LLM-HOST.md)

  actions on the Bank rail let you download a model's weights once to a local
