# 1.0.0-beta.4 — in progress

**State:** the next tag of the public line. Its changes are on the day-to-day
line and are listed under 1.0.0-beta.4 in the release notes the product shows;
this page names the headline items and what stays queued. The verdict, the
tag commit and the publish line are written at the tag.

**Ships in this tag**

1. **The built-in shell engine** — an optional, vendored bash-compatible engine
   behind the setting "Shell engine" (the system shell stays the default): one
   shell per session, so the working directory, variables, functions and
   aliases persist between Bash-tool calls; Windows runs it without Git for
   Windows; the pack is fetched per platform and built with cargo on Windows;
   the doctor names the live engine.
2. **On-device speech-to-text** — `/speak on`, space to talk, space to stop,
   with no API key and nothing leaving the machine; the on-device transcriber
   is preferred whenever its pack and model are present, a signed-in cloud
   transcriber serves otherwise, and `/speak options` lists the transcribers
   this install can use and saves the one you pick.
3. **The browser road for `/bug`** — when the GitHub CLI cannot file the
   report, the prefilled issue form opens in the browser and the link is
   printed in full.
4. **Agents that stop are no longer reported as throttled** — a recovery is
   charged only for the time it takes; a live but quiet stream is not cut at
   90 seconds; a stream that ends with a bare error reads its own closing
   reason first; the exit prompt and the crew view agree on what is running.
5. **Effort as a setting** — the ladder ends at max; the Agent tool takes an
   effort field, and sub-agent defaults (model, effort, how many at once) are
   settings with `/config` rows.
6. The fixes and changes listed in the release notes: the compaction request
   on the OpenAI road, the workflow-owned worker guard, the transcript pill,
   the repeat-install PATH line, the file-read line numbering, the Bash
   tool's single-quote escaping, the Godot addon and validation fixes, the
   Workshop cell parser, the render_tui tool outside the checkout, and the
   internal tidy-up.

**Still queued, not this tag:** the seat ceiling as a setting (a Boot Menu
"Seats" row, a `/config` row and `/seats N` as one door); Linux arm64 and
Windows arm64 archives (the installers say so today; Windows arm64 runs the
x64 build under emulation); the adviser tool; multiplayer; the design-tool
bridges.
