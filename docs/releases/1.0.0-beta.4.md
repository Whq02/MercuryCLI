# 1.0.0-beta.4 — in progress

**State:** the next tag of the public line. Its changes are on the day-to-day
line and are listed under 1.0.0-beta.4 in the release notes the product shows;
this page names the headline items and what stays queued. The verdict, the
tag commit and the publish line are written at the tag.

**Ships in this tag**

1. **The built-in shell engine** — optional, behind the `/config` row
   "Shell engine" set to `brush` (the system shell stays the default): one
   shell for the whole session, so the working directory, variables,
   functions and aliases persist between Bash-tool calls; Windows runs it
   without Git for Windows; the pack is fetched per platform and built with
   cargo on Windows; the doctor names the live engine. Two things it cannot
   do at this version on Windows: run a `.cmd` shim such as `npm` or `npx`
   directly (`cmd /c npm …` works, or `node` on the script), and find a
   program named by a relative path after a `cd` (use its absolute path).
2. **On-device speech-to-text** — `/speak on`, space to talk, space to stop,
   with no API key and nothing leaving the machine, once the install carries
   the on-device pack (the release archives carry it where the packaging host
   could build it; the doctor's Voice input row says) and you have fetched
   its model once with `/speak download` (60 MB, English; nothing is
   downloaded on its own). The on-device transcriber is preferred whenever
   its pack and model are present, a signed-in cloud transcriber serves
   otherwise, and `/speak options` lists the transcribers this install can
   use and saves the one you pick.
3. **A browser fallback for `/bug`** — when the GitHub CLI cannot file the
   report, the prefilled issue form opens in the browser and the link is
   printed in full.
4. **Agents that stop are no longer reported as throttled** — a retry after
   a quiet or dropped stream counts against the retry budget only for the
   time actually waited; a live but quiet stream is not cut at 90 seconds; a
   stream that ends in an error with no message reads its own closing reason
   first; the exit prompt and the crew view agree on what is running.
5. **Effort as a setting** — effort ends at max (the "ultra" level is gone);
   the Agent tool takes an effort field, and sub-agent defaults (model,
   effort, how many at once) are settings with `/config` rows.
6. **One spelling for the command line, the environment and the settings** —
   `--allowed-tools`, `--disallowed-tools`, `--dangerously-bypass-permissions`
   and `--allow-dangerously-bypass-permissions` are the option names;
   `--verbose`, `--include-hook-events` and `--mcp-debug` are gone (stream-json
   output no longer needs `--verbose`); `mercury auth token` replaces
   `setup-token`; an unknown option exits 2; every environment switch is a
   `MERCURY_*` variable and the older unprefixed names are no longer read; the
   machine-readable feed spells every key it defines in snake_case (feed
   contract 3); a settings file carrying an older spelling — a renamed key, or
   a renamed tool name in a rule or hook matcher (Task is now Agent) — is
   rewritten in place on first read, a project's checked-in file included; on
   macOS a sign-in that Mercury had been reading from another tool's keychain
   entry is no longer read, a config home other than Mercury's own keeps a
   keychain entry of its own, and a sign-in stored by a much older build needs
   a fresh one — each asks for one fresh sign-in.
7. The fixes and changes listed in the release notes: the Motion setting and
   the idle-cockpit fix behind it, the quiet start (no request of Mercury's
   own before your first turn beyond sign-in and the model requests), the
   usage meters read when shown, the MCP protocol update (2026-07-28), the
   permission ask that waits with no time limit, finished background commands
   collapsed into one line, the sign-in list with OpenAI first, the
   compaction request with an OpenAI model, the
   workflow-owned worker guard, the transcript pill, the repeat-install PATH
   line, the file-read line numbering, the Bash tool's single-quote escaping,
   the Godot validation fix, the Workshop cell parser, the render_tui tool
   outside the checkout, and the internal tidy-up.
