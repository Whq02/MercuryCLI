# 1.0.0-beta.14 — published 2026-09-18

**State:** published 2026-09-18 as a pre-release at
github.com/Whq02/MercuryCLI/releases/tag/v1.0.0-beta.14, tag on commit 97014e87.
The tag after 1.0.0-beta.13: the cleanup and the fixes of
2026-09-16 and 2026-09-17. Four switched-off estates removed from the product,
the queue that 1.0.0-beta.13 left, the defects found while Mercury ran its own
work, and the terminal checks brought from 27 green suites to 70.

## What changed

- Removed from the product: the dead and stale provider beta headers no longer
  ride a request; the context-management and cache-scope estates, the
  server-side refusal fallback opt-in with its advisor, and the experimental
  betas with task budgets and redact-thinking are gone. A request on the
  default path is byte-equal to before, but for the headers named.
- An empty reply on the OpenAI and Z.AI routes says why it carried no words —
  silence, the output cap, or an empty stream — and only the empty stream is
  sent again, once.
- A hosted shell's row in Runs opens a card with the whole command, its
  directory, the elapsed time, the exit code and the last lines of output, with
  a count of the lines shown; a long command is clipped so the output stays
  visible on a short window.
- Continue Last Session re-attaches to a session the daemon still holds instead
  of calling it runner-less.
- The effort chip, and the model and permission-mode words on the strip, catch
  a change within a bounded window when the facts feed drops the event.
- The DeepSeek rows follow the pricing page; DeepSeek's models come from its
  live list, with the dated rows standing in when the list is refused; the
  retired Flash id opens the Flash card.
- A pasted image survives a message that answers an open question.
- The /config Seats row shows its capacity without a keystroke; a rewind on a
  resumed session keeps its chain.
- A session that finishes elsewhere mints no note; a finished session not yet
  opened wears its state glyph in amber on the board until it is opened.
- Background commands that finish together start one turn, not one turn each.
- The enter screen's ready glyph is a pointer, not an emoji; the narrow board
  carries a park refusal's words; a notice of several rows stacks under the
  composer for its moment; the spinner's phase byline and the trace timing that
  never painted are gone.
- A dialog command's result of more than one line paints as rows on the chat
  instead of one clipped line; closing the only chat before its first message
  leaves two screens, not a third stop on a dead chat.
- A model or effort change made while a turn runs lands at the turn boundary,
  before the messages waiting for the next turn.
- The Computer tool refuses the window that holds the session, not every window
  of the terminal application, and checks the window again before each act; an
  edit refusal names which check failed instead of claiming the lines were
  read; a filename pattern with no separator walks only as deep as it says; an
  over-cap read carries its next window on every path, and a notebook names a
  bounded cell slice.
- On Linux the sandbox dependency check creates no process at boot, and the
  Linux archive carries the sandbox's unix-socket filter helper, so a Linux
  sandbox blocks unix sockets and `/sandbox` no longer warns that seccomp is
  unavailable.
