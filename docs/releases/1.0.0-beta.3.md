   with the roster key, a tag build with no key fails instead of publishing
   unsigned, the launcher is quiet when the archive is signed, and an unsigned

   hosted workflow never held the key. Done on `working`: the package job reads
   the repository secret `MERCURY_SIGNING_KEY`, signs every archive, reads it back

   archive names and the notes say `-unsigned`); the launcher's "unsigned" line is
   said once per install and `mercury doctor` says it every time (docs/TRUST.md).
