**What shipped (the bundled changelog is the one source; `mercury /release-notes` prints it):** sovereign mode as the one bypass; the computer-use access type under it; a line sent during a compaction no longer standing under the composer; the engine job service for Godot; the preserved-thinking notice moved out of the chat.

**Ships in this tag**

1. **Sovereign mode is the one bypass.** The Boot Menu's Sovereign mode row
   skips every permission question, computer use included, and the
   computer-use ask card's fifth answer turns it on. 1.0.0-beta.7 had shipped
   a second, narrower "sovereign" as a computer-use access type beside the
   old "Skip permissions at boot" row; this tag makes them one thing.
2. **The computer-use access type**, under Computer use in the Boot Menu:
   asks, permissive or full, with asks as the default. With sovereign mode on
   the default is full, and a saved value wins in either posture. Permissive
   lets the model work in the application in front when the turn began and
   asks once before any other application.
3. **A line sent during a compaction.** When the session's runner was
   replaced before it took the line, the row stood under the composer for
   good and could not be taken back. The row is now removed and a notice
   names the words to send again; a line the runner keeps is delivered once,
   in order, and its plate reads held while the compaction runs.
4. **The engine job service for Godot.** Mercury runs headless Godot workers
   itself, in parallel, each on a frozen copy of the project with its own
   user directory; a queue by priority; results in the runner's record shape
   with the failing lines; a compile gate in seconds; every engine owned as a
   process tree and ended on a timeout or a cancel. Five operations on the
   Godot tool and `mercury godot run|check|jobs|cancel|result` for scripts;
   the page is [VULCAN-GODOT-TOOLS.md](../VULCAN-GODOT-TOOLS.md).
5. **The preserved-thinking notice** no longer appears in the chat; the
   doctor and health rows carry the count and the cause.

**Known gaps in this tag**

- The engine job service's Windows path — the per-worker AppData folder, the
  console wrapper and the process-tree kill — is written from a Windows
  session's recorded facts and was proved only on macOS with Godot 4.6.1.
- With sovereign mode on and the access type pinned to asks or permissive,
  the ask card's note still says nothing asks after it.
- A scheduled wake that revives a session whose runner had gone idle can
  drop the session's preserved thinking once; the cause is the revived
  process re-encoding its history, queued for the next tag with a persisted
  prefix record.
- A relaunched runner is not handed the lines the replaced one still held;
  the notice asks for them again.
