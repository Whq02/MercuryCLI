# 1.0.0-beta.37 — ready for the tag

**State:** ready for the tag. A long session's automatic compaction now writes
its summary before anything is pruned, keeps your own messages and the last
ten complete rounds whole, and says exactly what it kept. A crewmate has the
same tools as the main chat, and every process it starts ends with it. Local
models that write their tool calls as text run them, keep the server's prompt
cache across tool steps, and are sized by the graphics card rather than the
system RAM. /effort and /health open as popup windows, and /zen hides both
rails for a full-width chat. The instructions sent before every conversation
are shorter with every behaviour kept, a pinned memory rule needs your own
asking words, Recall finds the matching fact first, and a set of fixes lands
for Windows test projects, deletes inside another user's folder, headless
"remember:" runs, memory conflicts, and the composer.

## What changed

- Added /zen: hides both rails for a full-width chat; /zen flips it, /zen on
  and /zen off set it, the setting persists and shows on /config as "Zen mode
  — rails hidden"
- Added mercury usage: it prints the /usage screen's compact figures line;
  mercury usage --json prints the whole reading (per signed-in provider the
  windows with used and reset, the figures and credits it stated, each with

  +1.2k"): how much the prompt side grew this turn, from the usage the turn

- Added a record of what was compacted to the compaction summary: the operator
  turns, the tool calls by name and count, how many failed, the compacted part
  of a turn that continues below, and the files those tools touched as paths
  to re-read
- Added a refusal, in an unattended session (a crewmate, a daemon worker, a
  headless run, a fired schedule), of git commands that discard work — a hard
  reset, a whole-tree checkout or restore, a forced clean, a forced branch
  delete, a force push — with the rule named and what to do instead; your own
  session, a Concourse cockpit included, keeps the ordinary permission card
  and runs them in sovereign mode
- Added the MoE coding tag qwen3.6:35b-a3b-coding (22 GB · 35B-A3B · 3B
  active) to the /localsetup pull list, sized by the same fit rule as the
  dense family
- Changed automatic compaction: it runs at the ordinary threshold before the
  window is reached, the summary is written before anything is pruned (a
  compaction that fails or is cancelled leaves the context as it was), every
  tool result that goes reaches the summariser first, your own messages from
  the compacted stretch ride whole, the last ten complete rounds stay when
  they fit, the run's state goes to project memory only once it has been read

- Changed a run's verification to read stale the moment a file changes after
