# 1.0.0-beta.27 — queued

**State:** queued behind 1.0.0-beta.26. This release adds the tokens each
sub-agent has used to the crew view, moves Apollo Mode into Strategy's place
on Shift+Tab, and fixes usage rows, result totals and reasoning counts on
the OpenAI-compatible models.

## What changed

- Added the tokens used, in and out with cache reads apart, beside each
  sub-agent's context in the crew view and under its tool card
- Fixed a local crewmate's context staying blank after a reply
- Fixed Shift+Tab stepping through Strategy mode; Apollo Mode now takes that
  stop and the ◇ mark, and Strategy stays reachable by its own command
- Fixed stream-json assistant rows showing zero usage on Grok, DeepSeek,
  Kimi, GLM and the other OpenAI-compatible models
- Fixed a resumed headless run reporting API time and cost from earlier runs
  in its result
- Fixed the reasoning-token count missing from Grok and other
  OpenAI-compatible results
