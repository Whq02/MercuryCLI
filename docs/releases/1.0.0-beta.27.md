# 1.0.0-beta.27 — queued

**State:** queued behind 1.0.0-beta.26. This release adds the tokens each
sub-agent has used to the crew view and a JSON export of the chat, moves
Apollo Mode into Strategy's place on Shift+Tab, and fixes doubled sub-agent
records, secrets printed in full, the Patience setting on seven providers,
temporary errors ending a turn, and the usage rows, result totals and
reasoning counts on the OpenAI-compatible models.

## What changed

- Added the tokens used, in and out with cache reads apart, beside each
  sub-agent's context in the crew view and under its tool card
- Added /export to a name ending in .json, a JSON copy of the chat with tool
  results trimmed and thinking left out
- Fixed a local crewmate's context staying blank after a reply
- Fixed Shift+Tab stepping through Strategy mode; Apollo Mode now takes that
  stop and the ◇ mark, and Strategy stays reachable by its own command
- Fixed stream-json assistant rows showing zero usage on Grok, DeepSeek,
  Kimi, GLM and the other OpenAI-compatible models
- Fixed a resumed headless run reporting API time and cost from earlier runs
  in its result
- Fixed the reasoning-token count missing from Grok and other
  OpenAI-compatible results
- Fixed every sub-agent turn being recorded twice in its transcript
- Fixed a sub-agent's answer to a message from the crew view also landing in
  the lead's inbox
- Fixed mcp get, mcp list, mcp add and the /mcp screen printing a server's
  secret values in full
- Fixed a session reopened from an editor over ACP coming back in the default
  permission mode instead of the one it was left in
- Fixed the Patience setting being ignored on Grok, Kimi, DeepSeek, Gemini,
  Muse, OpenRouter and Hugging Face
- Fixed an exported chat carrying API keys and tokens in full; they are
  masked in both the text and the JSON
- Fixed a temporary capacity or network error from OpenAI, Grok or
  OpenRouter ending the turn instead of retrying
- Fixed a network error ending a Kimi, DeepSeek or other compatible-provider
  turn instead of retrying
- Fixed overloaded sessions sending their retries in lockstep
- Fixed a settings popup hiding the session header while it was open
- Added an OpenRouter routing policy in /config, on from the start: no data
  collection and only endpoints that honour every parameter, with fallback
  and zero-data-retention choices
- Added a low-balance notice in /usage when an OpenRouter key's remaining
  allowance falls below ten dollars
- Fixed a slow model's turn being cut off after two minutes of silence; the
  normal wait is six minutes now, twelve in patient mode
