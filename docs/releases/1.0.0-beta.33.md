# 1.0.0-beta.33 — published 2026-10-12

**State:** published 2026-10-12 as a pre-release at
github.com/Whq02/MercuryCLI/releases/tag/v1.0.0-beta.33, tag on commit
ff226f38. A maintenance release. It fixes a few issues in the model's
instructions and ships a fix for the Windows update through the PowerShell
route. 1.0.0-beta.32 is deprecated with this release: its installed launcher
holds the version file open, so on Windows the one update from any version up
to .32 is run from Command Prompt.

## What changed

- Fixed a few issues in the model's instructions: shorter turns, the outcome
  first, and a short note left at the end of a session for the next one
- Fixed the journal entry to one line, written only when the memory.journal
  setting is true
- Fixed the Windows update through the PowerShell route: the launcher no
  longer holds the version file open, the version switch completes while
  another program holds that file, and a refused update leaves nothing behind.
  From 1.0.0-beta.32 or earlier, run the one update from Command Prompt: open
  cmd.exe and run mercury update. After it, updates complete from PowerShell
  too
