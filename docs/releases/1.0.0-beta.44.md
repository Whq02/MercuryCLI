# 1.0.0-beta.44 — published 2026-10-26

**State:** published 2026-10-26 as a pre-release at
github.com/Whq02/MercuryCLI/releases/tag/v1.0.0-beta.44, tag on commit
9b142d26. A feature, licensing and reliability release. Mercury CLI, its
release archives, the VS Code extension and the TypeScript and Python SDKs are
now licensed under the Apache License 2.0 (Apache-2.0), and README.md is a
single overview page paired with docs/INSTALL.md. Mercury connects 22 model
providers with the addition of Melious AI (/logins melious) and OrcaRouter
(/logins orcarouter), adds Kimi K3.1 Pro and K3.1 Pro Highspeed with low, high
and max effort levels, updates DeepSeek V4 Pro and V4.1 Flash wire handling
and model catalogues and pricing across OpenAI, Anthropic, Google Gemini,
Meta, MiniMax, Mistral, Z.AI, Qwen, Together AI, Fireworks AI, Cohere,
OpenCode Zen and Hugging Face, and switches a renting chat to its GPU rental
when ready while pausing on cluster or setup faults instead of terminating the
machine. ChangeSet adds exact-string edits[], file delete and file move
operations, Browser stores secrets in the macOS Keychain and fills
origin-bound TOTP codes, hooks match permission-rule clauses and support
failClosed, and Continue Last Session ignoring receipts sidecars, Arabic
rendering in macOS Terminal.app, and per-session daemon ▲ DEGRADED clearing
are fixed.
