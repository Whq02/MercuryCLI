# 1.0.0-beta.13 — published 2026-09-16

**State:** published 2026-09-16 as a pre-release at
github.com/Whq02/MercuryCLI/releases/tag/v1.0.0-beta.13, tag on commit 9d29cef1.
The tag after 1.0.0-beta.12: the harness-friction wave of 2026-09-15 — the
defects found in the owner's own sessions on GPT-6 Astra (the eleven findings
of the AVS2 analysis), the two watchers that ended sessions silently, the
bundled skills rewritten, and the four quick fixes from a bug hunt on the
owner's Windows box the same evening.

## What changed

- The run governor that ended a turn for repeating a tool call with nothing
  written in between, and the repetition breaker that ended a turn on repeated
  identical results, are gone: a session is never stopped for repeating
  itself. An empty provider reply is announced and the request is sent again
  once.
- The live token counter counts a tool call's streamed input, and the wide
  layout's count keeps pace with the stream.
- An edit refused for lines the model had not read carries those lines,
  numbered with their anchor; a read past the window cap answers its first
  window with the offset to continue.
- Superseded file results are pruned when the context reaches forty percent
  of the model's window (a setting), before a long session overflows.
- The lease verbs share one argument word; an empty shell command is refused
  before it spawns; a background agent's background command is recorded from
  its launch facts, listed on the tasks board, and reported back to the agent
  when it finishes.
- A lookup's empty answer from grep, pgrep, cmp, diff or test is a result
  naming its exit code; a real failure keeps its error.
- The Eval tool states its JavaScript kernel's environment; a failed cell
  names the fact and the import; two kernel faults fixed. A failed Workshop
  cell reports its own error, not the runtime's plumbing.
- A script run from inside a Mercury session no longer refuses the session's
  own environment stamp as foreign.
- The eleven bundled skills are rewritten from current documentation at
  about half their length.
- The DeepSeek route sends the reasoning effort where the API takes it.
- The turn receipt counts reads; the Boot face's MCPs & Skills page names
  what its empty states list; `--model` and `--effort` on the command line
  win over a resumed session's saved values and `/model` saves its choice; a
  rejected credential is refreshed once, then names the account and the
  sign-in; a run never records completed with deliverables still open.
