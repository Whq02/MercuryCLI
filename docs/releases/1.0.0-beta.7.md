**Ships in this tag**

1. **Samples** — off by default. Ask the model to show you something and it
   opens a page in your browser from its berth beside the session or with
   `/samples`; click a spot and write a comment, add a note, approve or ask
   for changes, and your marks come back into the chat; every version is
   kept; the Boot Menu's Samples row turns it on. Local only; nothing is
   hosted.
2. **Computer use on by default** — where the desktop driver is present. The
   ask offers a one-hour grant, a 24-hour grant and a sovereign mode that
   stops the asks; the Boot Menu carries a computer-use row with the access
   type under it, and `MERCURY_COMPUTER_USE=0` still removes the tool.
3. **The stream watchdog** — the "may be stuck" notice waits five minutes of
   silence; a silent connection on the Anthropic, Z.AI and OpenAI-compatible
   routes is redialled after two minutes instead of ninety seconds, OpenAI
   keeps fifteen; every wait of a minute or more is printed in minutes; and
   the status row counts the provider's heartbeats, so it no longer calls a
   live stream stuck.
4. **The updater** — inside a Homebrew or npm install, `mercury update` no
   longer installs a second copy the shell never runs; it names the command
   that updates that install, and the doctor says which `mercury` your shell
   runs.
5. **The composer** — a click lands on the character under it, a drag selects
   the typed words and never the frame, two clicks select everything; and the
   one-line notices that used to push the composer up now ride the hint line.
6. **Windows and every large window** — the renderer remembers the slices of
   clipped lines, so a frame costs about a third of what it did with nothing
   on screen changed; a new chat on a busy machine no longer boots its
   session runner twice.
