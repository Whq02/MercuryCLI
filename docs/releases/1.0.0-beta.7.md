# 1.0.0-beta.7 — in progress

**State:** the next tag of the public line. Its changes land on the day-to-day
line and are listed under 1.0.0-beta.7 in the release notes the product shows;
this page names the headline items and what stays queued. The verdict, the
tag commit and the publish line are written at the tag.

**Planned for this tag — Mercury working on itself.** The defects Mercury
showed while it built 1.0.0-beta.6 with its own agents, fixed at their owners:

1. **Notices that are read** — a ledger of unread notices, so an agent waiting
   on a completion it never saw is nudged instead of stalling.
2. **A scan mode** — a read manifest an agent must honour before it reports,
   and a sweep agent type built on it.
3. **The provider gate** — the delegation latches and an expired sign-in
   reported as what it is, never as an exhausted usage window.
4. **Teams that survive** — a teammate reported running after dying at spawn,
   a team lost on restart, a workflow failure line carrying the first agent's
   cause.
5. **The OpenAI route's tool calls** — empty placeholders stripped at the
   decode for every tool, the quote normalisation, an Edit refusal naming the
   read lines.
6. **Samples** — a page the model draws (a design at true cell size, a report,
   a comparison) and presents under the composer as a row in the agents list;
   Enter opens it in your browser; your marks come back into the session;
   versions kept per session.
7. **The seat count** — the daemon's own count of live workers, taken out of
   1.0.0-beta.6, revisited as a clearly explained proposal.
8. The items that ride along: the queued composer message drawn at its send
   time and delivered when an interrupt lands; the wider Edit and paste
   sharpenings; computer use's structured ask and global stop chord.

**Still queued, not this tag:** the boot-memory peak; the local benchmark rig
and the deeper per-call context cut it will measure; Linux arm64 and Windows
arm64 archives; the adviser tool; multiplayer; the design-tool bridges; the
response-length choice; the vendored shell.
