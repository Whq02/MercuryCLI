# 1.0.0-beta.34 — ready for the tag

**State:** ready for the tag. A field release: two testers ran 1.0.0-beta.33
for a day on a Windows box and a Mac, and this release fixes what they found,
with the bug hunt's findings beside it. One rename: the model's tool for
launching a helper is now called Crewmate, the word you already see on every
screen.

## What changed

- Added mercury://models: the model reads the providers you are signed into
  and their live model lists, so a family word such as "grok" runs that
  family's current model from your sign-in and an unknown id is asked of you,
  never guessed
- Added a Hidden characters row to /health: instruction files, skills and
  settings files are scanned for characters you cannot see but a model reads;
  a file that carries one is named
- Added a row under every permission card showing what you typed while it
  waited, so typed words no longer vanish
- Added an amber line under the Sovereign mode row while it is on: nothing
  asks or stops you — every action runs as you
- Added the build to mercury daemon status, and wall_ms to tool.after hook
  payloads
- Changed the model's tool for launching a helper to Crewmate (ResumeCrewmate,
  crewmate_type); earlier transcripts still open and resume
- Changed the macOS and Linux launcher to one process: a signal to the pid
  stops the run and ctrl+z hands the terminal back
- Changed mercury run to exit 0 only when it did what was asked: a question
  nobody could answer ends the run blocked with exit 1 and the way to resume;
  a mistyped slash command exits 1
- Changed Sovereign mode to put up no card of any kind — Windows shares, the
  Computer tool's first act and hooks that answer ask all run
- Changed a settings file that stops parsing mid-chat: the last good settings
  stay in force and the chat says so once
- Changed the end-of-session note and journal asks to ask for what you asked
  for, in your words
- Changed the browser's one-time download and first-visit cards to say what
  you are agreeing to before anything happens
- Fixed /exit: the session is asked once for its note before the terminal
  comes back, the row closes on Windows too, and the Leave card counts
  crewmates still at work
- Fixed the model seeing its own refusal on every later request, which made
  one refusal breed the next; a refusal is shown to you and never sent back
- Fixed a Windows daemon that could not start its control connection running
  on half-started and blocking every later start; it now exits, gives the home
  back and names the process and command that free it
- Fixed the home-delete guard to know the home wherever it is (Linux,
  relocated, quoted) and the Windows spellings; deleting your own folder
  inside the project by absolute path gets the ordinary card
- Fixed the task list on Linux reading in filesystem order; it reads in
  creation order everywhere
- Fixed a cd inside a Bash command moving the session's project folder
- Fixed the model picker: typing searches and no letter saves (ctrl+w window,
  ctrl+e effort); names are matched before saving and typos never saved;
  image, video and speech models are never offered for chat; "saved as your
  default" is said only when it was
- Fixed a visit to the Session Concourse saving another session's model as
  your default
- Fixed /appearance digits, a /config theme pick surviving esc, and the
  Thinking row reading what the engine runs
- Fixed what the model knows after a /model switch: it can look itself up
  (mercury://seat), the chat row says what happened to your default, and an
  empty thinking block says so
- Fixed memory: an over-long fact is refused whole, a key- or password-shaped
  fact is refused by memory itself, "forget it" and "that's wrong" work on a
  fact stored minutes ago, a pending fact opens whole and can be corrected,
  retired or pinned, typing never unpins, undo is named, the lineage counts
  you once, and --ephemeral leaves nothing behind
- Fixed Edit's "read the file first" refusal carrying lines or a digest of a
  file you may not read
- Fixed Write and Edit rewriting CRLF endings, the trailing newline and the
  byte-order mark; the append card shows the line added; a refused edit
  carries its reason
- Fixed /health reading fault instead of caution on an install nobody signed
  into, a false TAMPERED after first boot, a silent signed-out state, and a
  browser sign-in with no code saying nothing for ever
- Fixed the Session Concourse composer starting a session on one ↵ from a
  restored draft; it is labelled and needs ↵ twice; the status row returns to
  ready; /runs and /crewmates agree; when every place under /seats is taken a
  chat waits twenty seconds for one to free and names what frees it
- Fixed faulty hook entries dropped in silence; each is named with its path
  and fault, wrong setting values say what they accept, and a hook holding a
  call is shown ticking
- Fixed the always-allow option on a card to say what it writes, "Ran" said
  for commands that never ran, and a message typed under a card landing inside
  the tool output instead of as your instruction
- Fixed the browser tool reporting success on a dead server, swallowing
  refused downloads, and not saying what a click caused
- Fixed headless runs losing piped text after one second, --json verdicts
  missing from stdout on failure, stacks in error detail, a cost_usd number on
  a subscription, and two hidden close calls billed per run; a prompt
  beginning with - and PowerShell's dropped -- are explained
- Fixed the Black and white theme losing bold, dim and reverse; PageUp and
  PageDown in /help and /health; the welcome card, critter label, theme names,
  wake times, the /seats refusal, Windows terminal check and installer line
  now in plain words
- Fixed the last "agent" words where a crewmate is meant, and the 24-bit
  colour row on Windows
