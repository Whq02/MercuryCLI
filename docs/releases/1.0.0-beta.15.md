# 1.0.0-beta.15 — ready for the tag

**State:** ready for the tag. A short update on quality: the defects found
while Mercury ran its own work, one update command for every install channel,
the notepad curator retired, and the terminal checks brought further toward
green.

**Verdict:** hosted gate run 35401632019 on the release line's published tree
(commit 79a288f8), 138 of 138 release suites green; the gate-ledger row
whose code tree equals the tag's. The terminal drives, an advisory class, read
74 of 77 suites green on run 35397922412; what they still show is recorded
on the 1.0.0-beta.16 page.

## What changed

- One update command for every install channel: `mercury update` inside a
  Homebrew or npm install asks once and runs that channel's own upgrade with
  its output streamed, then re-reads the installed version; `--yes` skips the
  question; `--check`, `--status`, `--rollback` and the doctor say the same in
  every channel; an npm-made install is named for what it is.
- The boot screen says once per newer release, in its bottom-right corner,
  that an update is available, from the update notice's cached answer; the
  chat's expiring line stays.
- The shared daemon outlives the Mercury that started it: when that window
  closes, the daemon passes to the oldest open Mercury still holding a session
  and stops only when the last one closes; a restart armed by a new build
  waits for every live session, including one opened after the arming.
- A refused send keeps the pasted text: the pastes come back with the words,
  so the next send carries them.
- `/release-notes` is `/update-notes` (the old name still answers for one
  release): the card shows the running release's section with the earlier
  releases one key away in the transcript pager; a headless print carries
  every release.
- A long command result no longer ends in a tall empty band, and the last
  character of a full-width line no longer hides under the pane's edge: the
  text is measured at whole cells and the gutter keeps its width, so a line
  that filled the old span wraps one column earlier at 120 columns and above.
- Minerva, the notepad curator, is retired: its room and `/tabula`, the
  `/minerva` command, the ask line on the rail's notes card, the MINERVA tab of
  the prompts panel, the boot-menu row and the minerva sub-model container are
  gone; the notepad and `/note` stay as manual capture under a TABULA card, the
  prompts panel keeps its three tabs, `/submodels` is the Console's picker, and
  a configuration that still carries Minerva's settings is read without
  complaint.
- One notice enters a session's own context when its provider's usage window
  is about to close: the provider, the window, the percent used, the reset and
  what to do before the stop; once per window, never from a provider that
  states no usage.
- The context figure on the rail says "pin" while it shows a provider's pinned
  window, until the account's live list answers with the real figure.
- The command palette, the file opener and the content search no longer vanish
  when opened in the first seconds of a session: the layout no longer remounts
  when the session's process connects.
- A closed chat that never held a message says the truth on its stopped row
  and its receipt; a queued row's state fits its cell at 120 columns.
- The doctor's sandbox row on Linux says whether unix sockets are blocked,
  from the sandbox's own facts: blocked with the helper, open without it, open
  when the setting allows all unix sockets.
- A failed Workshop cell opens as a card with its code, the whole error and the
  output tail, one keystroke from its row through `/tasks` and the cell's id.
- A background sub-agent carries the Sleep tool; its wait ends when the shells
  it launched settle, never on a bare timer.
- A receipt on the composer's hint row reads whole at ordinary widths: while a
  receipt or notice stands the hints step aside and it takes the whole row.
- The failover route's amber sentence stands two minutes after the switch and
  after each change of state instead of the whole week; the strip's model
  segment carries a failover mark for as long as the session runs on that route,
  and `/model` is still the way home.
- The running turn's token figure reads the wire's output tokens for every
  provider once usage has arrived, thinking included, and shows its estimate
  mark until then.
- The Edit tool no longer turns straight quotes into typographic ones inside
  code: its quote-style preservation applies to prose alone, and code lands
  byte for byte in every language.
- The rail shows a new mission's card the moment it is born.
- A new chat is born at the operator's saved effort, from the boot screen and
  the New Session strip alike; the daemon's high stands only when nothing is
  saved.
- Words typed after a mid-turn model or effort change no longer run on the old
  model when the turn still has tool rounds ahead: they wait for the turn's
  end and run as the next turn on the switched model; a sub-agents or
  workflows switch made mid-turn lands at the turn's end too, and words typed
  after it run with the switched roster.
- A mission set in a chat's first seconds is no longer lost: a mission armed
  while the chat is still landing follows the session at admission, so its
  card, its rail row and the runner's stop check see it.
- The rate-limit fixture seam that armed builds carry (`/mock-limits`) runs in
  the screen's process, where the failover offer card reads it, so a
  daemon-hosted chat's scenarios arm the latch the card derives from; the
  cap latch writes on the debug log when it is observed, cleared and read.
