# 1.0.0-beta.15 — queued

**State:** queued behind 1.0.0-beta.14. A short update on quality: the
defects found while Mercury ran its own work, and one update command for every
install channel, tested on Windows and on a second Mac before the tag.

**First in this tag:** the terminal drives brought to green. They are the
advisory class a release does not wait on; on the 1.0.0-beta.14 line seven of
their proof files stayed red after eight hosted runs, none a regression: three
wait on a design decision, one is a standing candidate this Mac never read,
one is a timing race on the hosted runner, two appeared on the last run only.
Each is read and either fixed or ruled, one hosted run per fold, until every
suite of the class is green.

**Second:** the shared daemon outlives the Mercury that started it.
Today one daemon serves every Mercury on the box and belongs to the first one
opened; when that one closes, or a restart armed by a new build fires, the
others lose their runners until a message revives them, and a pasted text dies
with the runner. The daemon passes to the next live Mercury, a restart hands
live runners over, and a paste survives.

1. **One update command** — `mercury update` runs the channel's own upgrade for
   a Homebrew or npm install, with one consent line, and `--check` reads one
   release feed on every channel.
2. **A notice before the limit** — a session close to its provider's usage
   limit gets one notice, so an agent finishes and saves its work before the
   stop.
3. **The context-window figure** — the rail shows the pinned window until the
   live list answers; the pin is marked as a pin until then.
4. **The receipt row** — a receipt takes the whole hint row for its seconds, so
   the default-provider confirmation fits at ordinary widths.
5. **The mid-turn switch's remaining case** — words typed while a turn still
   has tool rounds ahead join that turn and run on its model; the spawn
   switches and the kit dials on the same boundary.
6. **The doctor's sandbox row on Linux** — the row says whether unix sockets
   are blocked.
7. **A Sleep tool** on a sub-agent's roster; the failed Workshop cell as a card.
8. **Windows** — the setup chain's entry, and the remaining audit findings.
9. **GNU bash 5 vendored** — an MSYS2 bash with a coreutils pack for Windows,
   bash 5 for macOS and Linux, the GPL notices and the source offer carried in
   the archives; the bash-compatible engine that 1.0.0-beta.10 bundled stays as
   the fallback. Moved from the 1.0.0-beta.14 plan.
10. Carried from the earlier plan: a scan mode with a read manifest; the
    daemon's own count of live workers; the wider Edit and paste sharpenings;
    the dependency index; coverage and test-to-debug; the update notice's
    command; the small words.

**Provider breadth, 1.0.0-beta.16:** Perplexity — a search tool on its Search
API, its router models as a keyed provider with a live catalogue, and its agent
endpoint as a seat driven by Mercury's own tools.
