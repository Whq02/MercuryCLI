# 1.0.0 — ready for the tag

**State:** ready for the tag. The Computer tool reads a screen as a short
numbered outline and acts by row number, so a model finishes a desktop task in
a handful of calls instead of dozens; Mercury serves its own tools to other
agents over MCP; and mercury tune trains a model on your own sessions and
installs it locally. Local images and video run on x64 Windows and Linux, with
SDXL and Pixel Party XL, reference images and masks, your own checkpoints and
LoRAs, and ControlNet with batches and palettes; a project's MCP servers start
only once you approve them, the update notice is yellow and stays until you
update, and a repository's own git helpers never run inside Mercury's git
commands. Every model reads documents, the Document tool writes them, and a
run sends less with each request, makes fewer requests and asks less often in
flow mode, with every capability kept; Mercury leads with the answer and acts
on a result in the turn it arrives. Fixes land for small local models,
headless runs, crewmates, /compact, and /imagesetup and /localsetup on
Windows.

## What changed

- Added the Computer tool's outline: tree and find return numbered rows, an
  act names ref: 7 instead of pixels, root: scopes a read to one dialog, a
  result's second line says what is on the screen after the act (changed ·
  now: window "…" · focus …), an ambiguous target lists its candidates and nth
  picks one, wait takes a text, a window title, a URL or gone: true, and read
  returns a labelled value or the clipboard under its own card; a desktop task
  that took 44 calls takes 7 (docs/COMPUTER-USE.md)
- Added Mercury as an MCP server: mercury mcp-server serves run, session rows,
  sessions, send and recall to any MCP client over stdio or token-protected
  HTTP on the loopback, so another agent can hand Mercury work and read what
  it did (docs/MCP-SERVER.md)
- Added mercury tune: export your own sessions as a scrubbed training book,
  have a model write the reasoning for each turn, train an adapter on a rented
  GPU through /llmhost with a money pause that never terminates the machine,
  bake your charter into the chat template and install the result into the
  Bank for /localsetup; the page states the developer's own results plainly
  (the mercury-tune extension's TUNE.md)
- Added local images and video on x64 Windows and x64 Linux: /imagesetup pulls
  the Vulkan build of the runtime, or the CUDA 12 build on Windows with an
  NVIDIA card, and the runtime row names the build (docs/MEDIA.md)
- Added document reading on every model: a PDF opens as numbered text with
  page markers, and pages gives page pictures on an image-capable model;
  office documents keep their headings, lists, tables, notes, comments and
  formulas; scanned pages and images read through the system's OCR (macOS
  Vision, Windows OCR, an installed Tesseract), Arabic among the languages;
  Grep searches documents with page and sheet labels; a fetched PDF comes back
  with its saved path and its first page; native PDF input rides OpenAI,
  Gemini and Mistral (docs/DOCUMENTS.md)
- Added the Document tool: it creates DOCX, PDF, PPTX, XLSX, HTML and Markdown
  from Markdown or structured content, converts between them, merges, splits
  and rotates PDFs, writes a bibliography in APA, IEEE, Chicago or Harvard
  with DOI lookup through Crossref, and inspects a document's structure
  without reading its body; every write rides the usual permission check
  (docs/DOCUMENT-TOOL.md)
- Added four debug adapters: Flutter, CodeLLDB (preferred for Cargo projects),
  PHP with Xdebug, and Bash with bashdb; CodeLLDB and PHP Debug download once
  on your approval
- Added /copy: the last reply goes to the clipboard whole, with its line
  breaks, emoji and right-to-left text; /copy 2 is the reply before, /copy
  code the last code block, and ctrl+x y runs it or copies a focused message
- Added browser frames and forced clicks: frame reaches an element inside an
  embedded map or form, and force: true clicks a covered target the model has
  read
- Added batch fetch: WebFetch takes up to three URLs in one call, with a
  result for each
- Added SDXL and Pixel Party XL to /imagesetup: the sdxl-base-1.0 and
  pixel-party-xl rows pull from Hugging Face with the licence on the card, a
  pull joins the model's four parts into one checkpoint on your machine and
  says what the download needs while it runs, pixel-party-xl's card asks for
  its . in pixel art style suffix, and downsize saves a pixel-art picture at
  its native size beside the full render (saved at 128×128) (docs/MEDIA.md)
- Added reference images and masks on every image model: reference_image with
  a strength from 0 to 1 (0.75 by default) starts a render from your own
  picture, mask (white paints, black keeps) repaints part of it through the
  model's ordinary weights, the engine centre-crops and resizes both to the
  render, and the Local image card names the reference, strength and mask
  (docs/MEDIA.md)
- Added your own checkpoints and LoRAs: /imagesetup <file or link> registers a
  safetensors checkpoint with its family read from the file's header, and
  loras applies LoRA files or Hugging Face and Civitai links at explicit
  weights, matched to the model's family (docs/MEDIA.md)
- Added ControlNet, batches and palettes: SD 1.5 and SDXL control rows in
  /imagesetup (canny from a PNG's edges, depth and pose from prepared maps),
  count renders up to 16 frames on consecutive seeds, sheet lays them out as a
  PNG grid, and palette maps a pixel-art picture to its most-used colours or a
  .gpl or .hex palette file (docs/MEDIA.md)
- Added GPT-6.1 Terra to the model picker with its window, output ceiling,

- Changed the update notice: vX.Y.Z available — mercury update shows in the

- Changed project MCP servers to start only once approved: a server in

  interactive start shows, or with kit.trustProjectServers in your own

- Changed MCP details, hooks and the SDK: an environment placeholder in a
