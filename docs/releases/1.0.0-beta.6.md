# 1.0.0-beta.6 — published 2026-09-11

**State:** published 2026-09-11 14:13 as a pre-release at
github.com/Whq02/MercuryCLI/releases/tag/v1.0.0-beta.6, tag on commit f1ec26d4.
The release in which Mercury was measured and the chat was steadied: 561 commits
since 1.0.0-beta.5.

**What shipped (the bundled changelog is the one source; `mercury /release-notes` prints it):** computer use behind `MERCURY_COMPUTER_USE` on every provider route that carries images; stop, pause and kill controls for workflows from any session; a compact layout for a small or resized terminal, with no minimum window size; rarely used tools loaded on demand; the child-memory guard on by default, parking a session instead of killing it; guidance to batch independent reads; preserved reasoning kept across an idle hour, a prune, a resume, a credential refresh, a reconnect and a mid-conversation tool mount; the streamed reply no longer hides for a moment when its reasoning lands first; a finished agent's report arriving once; a shell command with an ampersand and a glob no longer ending with exit 127; headless planning without an approval channel refused instead of trapped; tool descriptions that name only offered tools; the Edit tool accepting a model that sends every field; a spurious input-stream error while recording voice gone; the doctor's bug-report link; internal checks that no longer applied removed.

**Ships in this tag**

1. **Computer use** — behind `MERCURY_COMPUTER_USE`, the model takes
   screenshots and drives the mouse and keyboard on every provider route that
   carries images; the first act in each application asks by name, Esc stops
   it, one session drives at a time, and screenshots never enter the saved
   conversation.
2. **Workflow controls from anywhere** — stop, pause and kill an agent of a
   workflow from any session, and after a compaction or a clear.
3. **The compact layout** — on a small or resized terminal the session's
   critter and facts sit in a band at the top, the chat takes the space, one
   line under the composer names the sessions and agents, the Session
   Concourse becomes a split view, and there is no minimum window size.
4. **Lighter calls** — rarely used tools load on demand; a first request
   carries a third less definition text, and on the OpenAI route a third of
   its former bytes; the guidance asks for independent reads in one message.
5. **The child-memory guard** — on by default, and a session that crosses it
   is parked, not killed.
6. **Preserved reasoning that stays** — no longer dropped after an idle hour,
   a large prune, a resume, a credential refresh, a reconnect, or a
   mid-conversation tool mount.
7. **A steady chat** — the streamed reply no longer hides for a moment when its
   reasoning lands before its words; a finished agent's report arrives once.
8. **Fixes** — a shell command with an ampersand and a glob ending with exit
   127; planning without an interactive approval channel trapping a headless
   run, now refused; tool descriptions directing a sub-agent to a tool it does
   not have; the Edit tool refusing an edit from a model that sends every
   field, empty ones included; a spurious input-stream error shown while
   recording voice; the doctor's bug-report link.
9. **Removed** — internal checks that no longer applied.
