# 1.0.0-beta.26 — queued

**State:** queued behind 1.0.0-beta.25. This release adds two model
families, xAI's Grok and Meta's Muse, a per-chat advisor switch, the credit
balance beside every sign-in's meter, and fixes a full conversation getting
stuck when compaction was off, a full usage window saying only that it was
reached, a tool row counting on after its tool had finished, and a very long
prompt hanging before anything was sent.

## What changed

- Added xAI's Grok models: sign in with your Grok subscription or an xAI API
  key from /logins, pick a Grok row in /model, and say grok to mean the newest
  one; an optional management key shows your team's credits, this cycle's
  usage and its spending limit in /usage
- Added Meta's Muse models: /logins meta connects a Model API key, and muse
  follows the newest Standard model your account serves
- Added /advise, which turns the advisor on or off for the chat it is typed
  in: a new chat starts off, /advise alone says the state, a resumed session
  remembers it was on, /config → Advisor is the settings for every chat and
  off there stops them all, and a headless run turns its advisor on with
  --advise
- Added the advisor's interval in minutes (10, 20, 30, 45 or 60), its notes
  arriving marked as the advisor's own and never as your prompt, and a small
  "advisor · every N minutes" chip on the chat's status row while it is on
- Added the credit balance beside every sign-in's meter: the ChatGPT
  sign-in's credits, the Claude subscription's extra-usage figure, Kimi's
  Extra Usage balance with its plan windows, the Hugging Face plan, and a
  plain note of what Google does and does not report
- Added deepseek, kimi and glm as model words: each picks that family's
  newest model, the way grok does; the start screen's model strip names the
  DeepSeek, Kimi and GLM models too
- Added a warning on machines under 16 GB when a local window you pick leaves
  too little memory free, naming the biggest smaller window that leaves room;
  auto still takes the biggest window that fits
- Fixed the advisor running in every session at once whenever the settings
  were on: it runs only in a chat that asked for it, and crewmates are never
  advised
- Fixed a full conversation getting stuck when Auto-compact was off: an
  emergency fold now lets the session continue, and automatic compaction
  starts 20,000 tokens before the context's usable limit
- Fixed a full usage window saying only that it was reached: the warning, the
  meters, the offer cards and the refusal now say what carries your requests
  from there — extra usage, credits, a wallet — or that nothing does until the
  reset
- Fixed a tool row's seconds counter and running mark carrying on after the
  tool had finished in a session viewed on the switchboard; a running row now
  counts from when the call was made
- Fixed a very long single-line prompt hanging the session before anything
  was sent
- Fixed the exact token count running low after a thinking turn: the count
  now includes everything the next request will carry, /context's Messages
  row reads the full figure, and a refused count retries briefly and says why
- Fixed /logins opening as a bottom panel: it now opens as a popup like
  /config and /usage, at every terminal size, with your signed-in accounts and
  their sign-out inside it
- Fixed an idle session checking a crew file once a second when it had no
  crew
- Fixed a parked session's own check-back wake reading "1 scheduled · due
  now" for as long as it stood: the rail now says what stands, and
  interrupting, parking or stopping a session drops its pending self-paced
  wakes
- Fixed an agent's worktree starting from a stale copy of the main branch,
  and two worktrees launched together colliding on the repository lock
