# 1.0.0-beta.11 — at the gate

**State:** release candidate, a maintenance tag after 1.0.0-beta.10 on the
same line. The two items below are on the release line; the hosted gate runs
on it; the verdict, the tag commit and the publish line are written at the
tag. The list that was queued under this number is now
[1.0.0-beta.12.md](1.0.0-beta.12.md).

**Verdict:** written at the tag.

**What shipped** (the bundled changelog is the one source; `/release-notes`
prints it):

1. **A line sent while a sub-agent works reaches the session's own model.**
   In a chat run through the daemon, a line typed while a sub-agent ran was
   taken by that sub-agent: the words landed in the sub-agent's record, the
   session's model never saw them, the row on screen stood with the wrong
   time until a ten-minute bound, and the same words were sent again. The
   mid-turn delivery now reads the agent id first, so a sub-agent never takes
   the operator's line; the row lands once, with the time it was sent, and the
   model answers it. Proved on macOS and on a hosted Windows runner.
2. **The daemon's memory limit on session runners is removed.** A runner over
   a built-in size was parked after its turn, which ended every sub-agent and
   workflow running inside it, on a machine with memory to spare. The limit,
   its setting and its sweep are gone: a session is never parked or restarted
   for its memory use. The box's load and free memory stay visible to agents.

**Known gaps and the queue:** everything queued is on
[1.0.0-beta.12.md](1.0.0-beta.12.md). A doubled row that is not a stray echo
beside a re-send would be a second cause this tag did not look for.
