# 1.0.1 — ready for the tag

**State:** ready for the tag. Mercury CLI 1.0.1 adds editable image pipelines,
image and video generation on rented GPUs, Aseprite drawing tools and OAuth
sign-in for MCP clients. It includes a bundled Python runtime for debugging
and fixes for document reads, updates, model usage and sessions.

## What changed

- Added images and video on a rented GPU: choose an existing SSH rental in
  /imagesetup, send reference files over its tunnel and save the results to
  your project; setup and generation use the rental's hourly rate.
- Added editable image pipelines: save named steps in a project file, run from
  a chosen step and reuse earlier outputs whose inputs and saved files still
  match, locally or on a rented GPU.
- Added ComfyUI workflow import and export: inspect a supported workflow
  without rendering, turn it into an image request or editable pipeline, and
  export compatible steps; unsupported nodes are named.
- Added image upscaling with downloadable upscalers, a chosen enlargement
  factor and saved full-size results, including batches and sheets.
- Added per-image samplers, schedulers and textual-inversion embeddings, with
  family matching and the applied settings in each result.
- Added Aseprite drawing and named parts: draw pixels, lines, shapes and
  fills, arrange layers and groups, duplicate frames, check palette colours
  and view a PNG without changing the sprite's size.
- Added OAuth sign-in for ChatGPT MCP connections: approve a connection with
  the code printed by mercury mcp-server and give each client its own
  permitted sessions.
- Added a bundled Python runtime for debugging: no separate Python
  installation is required; scripts use a project's Python 3.10 or newer when
  available, otherwise the bundled interpreter.
- Added the image-generation skill for prompts, reference edits, masks, pixel
  art, editable pipelines, workflow imports, upscaling and video.
- Added OpenRouter budget readings: usage shows the enforced budget's
  remaining amount and reset, alongside the key cap and daily free-model
  requests.
- Changed the Shift+Tab mode carousel to include Sovereign in interactive
  sessions unless settings or policy disable it; unattended runs require
  --sovereign or --allow-sovereign.
- Changed mercury update to follow the installed version's channel: full
  releases take the next full release; beta and release-candidate installs
  take the newest release, full or pre-release.
- Changed Flow's shell approvals to accept a literal change to the current
  directory, checked absolute mkdir paths, quoted pipeline status in echo and
  checked brace groups; refusals name the argument or command form to use.
- Changed hosted requests to load supporting tool descriptions on demand while
  keeping every tool, reasoning setting and output limit available.
- Changed source builds to use Bun 1.4.4; release archives run on Node 24 LTS.
- Fixed document-read failures: damaged files name the file and cause,
  encrypted PDFs ask for an unencrypted copy, and scanned PDFs without OCR
  name the platform's installation step; the session can continue reading
  files.
- Fixed MCP calls with unused optional fields set to null: fields the server
  does not accept as null are omitted when optional.
- Fixed MCP authentication and HTTP client isolation, including credentials
  forwarded across redirects and messages reaching the wrong client.
- Fixed shell quoting and HTTPS connections for command-injection,
  certificate-check and stalled-connection failures.
- Fixed Mistral model selection, reasoning levels and token prices so requests
  keep the selected model and effort.
- Fixed Ollama reasoning settings to use the model's declared choices and
  default.
- Fixed costs for models served remotely through Ollama: an unknown remote
  price is not counted as free local inference.
- Fixed Qwen cost estimates to follow the connected endpoint's region and
  plan.
- Fixed Kimi cache costs to count cache reads, ordinary input and cache writes
  separately, including one-hour writes.
- Fixed Fireworks usage to distinguish uncached and cache-adjusted prompt
  limits.
- Fixed MiniMax pricing at 512,000 input tokens to use the standard tier.
- Fixed JavaScript debugger attachment on Node 24, pause requests while
  stepping and completion results.
- Fixed Cargo test breakpoints in projects reached through symbolic links.
- Fixed TOML and YAML syntax checks on Write and Edit to work on the bundled
  runtime and name the error's location.
- Fixed a session consuming a full CPU while crewmates were running and an MCP
  client sent it a message.
- Fixed resumed crewmates losing their reasoning budget, effort or required
  output format.
- Fixed piped output losing its final bytes when the reader is slow.
- Fixed startup from a deleted folder to give a short error rather than a
  crash report.
- Fixed small media downloads to show their size in MB rather than a rounded
  zero in GB.
- Fixed Windows source builds rejecting the bundled Python licence files after
  checkout.
- Fixed the session reopen message calling a newer Mercury build older.
