# 1.1.1 — ready for the tag

**State:** ready for the tag. Mercury 1.1.1 adds Profiles to the home screen
so you can run separate config homes side by side with their own logins,
settings, history and memory while sharing the installed program and your
project folders. mercury -c, Continue Last Session, /sessions and Session
Manager now order and age chats by when you last talked to them rather than by
file write time, and a session resumed after a compaction or from a file over
5 MB opens at the end of its conversation with parallel tool results and
crewmate replies intact. The home screen, Boot Menu, chat layout, composer
footer, Session Manager, side rails, a crewmate's view, /model, /critter, tool
rows and pop-ups drop extra borders, icons, gaps and repeated words, keeping
the composer footer to one row in every state, and Mercury now asks the
terminal once and uses 24-bit colour where the terminal answers. Subscription
sign-ins coordinate refreshes across windows and keep expired rows visible, a
sign-in address that could not be copied can be shown on one line, /model and
/effort in a crewmate view open the chat's own pickers, and the Bash,
Computer, Browser and TypeScript language-service tools avoid stalls, stale
rename errors, misread exit codes and false refusals. Updating is recommended
for every install: this release closes a case where a file deny rule on
Windows was not applied to some Bash commands.

## What changed

- Added Profiles to the home screen, under Boot Menu. Creating a profile makes
  its own config home beside the first (~/.mercury2, ~/.mercury3, and so on)
  with its own logins, settings, history and memory, and writes a matching
  command (mercury2, mercury3; on Windows mercury2.cmd, mercury2.ps1 and a Git
  Bash command, switching cmd.exe to UTF-8 for non-ASCII home paths) that
  shares the installed program. Project folders, downloaded browser builds and
  your user MERCURY.md and rules folder from the first home are shared,
  user-made skills copy into a new profile switched off, and each new profile
  starts on the next critter (crab, octopus, jellyfish, clam, then round
  again) until you pick one with /critter. Profiles can be renamed or removed
  from the same screen (removing deletes the command and keeps the folder and
  logins), updates keep versions still running in any profile and refresh
  managed profile commands, and mercury install --uninstall removes those
  commands.
- Changed the home screen and Boot Menu: the home screen drops its left accent
  bar, row icons, the dots between its key hints and the "open in another
  window" note on Continue Last Session, and its Session Manager (Concourse)
  row reads Session Manager; the wordmark shimmer makes one softer 2.7-second
  pass instead of oscillating for 10 seconds, no longer runs on the selected
  menu row, and sits over a plain hairline divider. The wide Boot Menu and its
  pages use one frame without upper-case section headers, hide the banner when
  the list and detail need the height, rename the saved boot-defaults label
  from "Profile" to "Saved", shorten repeated labels, and drop (>_) from the
  classic Boot Menu header and pre-boot line. The first-run theme step draws
  its critter still.
- Changed the top status band and work area in a chat to drop their nested
  rounded borders, leaving a single hairline divider, and removed the pulsing
  dot and repeated intro lines from an empty chat.
- Changed tool rows to drop their left accent bar and tool-family glyphs, use
  one space between the timestamp, [Mercury], the tool name and its target,
  place the ✕ of a failed or declined row in the first column, and drop the ⦿
  prefix from permission card titles.
- Changed pop-up headers to drop the crab glyph badge and header shimmer.
- Changed the composer footer to stay one row tall in every state: at rest it
  reads ? for shortcuts · ctrl+x p commands + files, with the side-rails
  shortcut moved to the rotating tips.
- Changed background crewmate, Bash and PowerShell launch rows to drop their
  (↓ manage) hint.
- Changed a crewmate's view to use the chat's own rows, composer footer and
  status row: its separate header card is gone, the status row reads viewing
  <name> (main chat: <name> when a crewmate is pinned as the main chat) in
  place of the longer composer → and commands → wording, and ? shows what esc
  does there and the way back to Mercury Lead.
- Changed /model and /effort typed in a crewmate's view to open the chat's own
  pickers and change that crewmate.
- Changed /saturn and /schedule into one /schedule command: running /schedule
  alone opens the schedules board as a pop-up over the chat, and /schedule
  <what and when> schedules directly; /saturn is retired.
- Changed the Session Manager board to drop header glyphs and the status
  rail's border, lowercase its headings (sessions, status & title, project,
  now, last used, parked, other projects, needs you) and the section titles
  inside ?, shorten the new-session tab to + new · n, trim repeated hints,
  thin the resting bottom legend to tab, /, ? and esc (listing selected-row
  keys inside ?), and show ⌃j for a new line in terminals that do not report
  shift+↵.
- Changed Session Manager to show ↵ queue when you type to a working session.
- Changed the side rails to drop their lanes and vitals heading rows,
  lowercase their panel titles, show the crew panel's title as crew <N>, title
  the usage block of the single-rail layout usage, and shorten row labels.
- Changed /model to drop the rounded box around the selected row in favour of
  the ❯ pointer, and to show OpenAI rows as pending rather than unavailable
  while the live catalogue loads.
- Changed /critter to replace its four cards with a four-row list beside one
  live preview, folded the /runs legend into its footer, and highlighted armed
  stop confirmations in amber on /runs and /crewmates.
- Changed sent messages with images so they no longer draw a separate grey
  [Image #N] attachment row when the prompt text already names that image.
- Changed mercury -c, Continue Last Session, /sessions and Session Manager to
  order and age sessions by when you last talked to them, not by when their
  file was last written. In Session Manager a session you last talked to more
  than a week ago stands under older chats even when its file was touched
  since, and a session that holds only a failed sign-in ranks below chats with
  messages.
- Changed how Mercury chooses its colours. When a terminal does not announce
  24-bit colour, as over SSH or in a container, Mercury asks the terminal once
  at the start of a session and uses 24-bit colour where the terminal answers.
  On a 256-colour terminal each colour is now the closest match to its 24-bit
  value, on a 16-colour terminal Mercury paints in the 16 basic colours alone,
  and a terminal whose TERM name Mercury does not know gets those 16 colours
  instead of none.
- Changed release packaging and mercury update so each archive ships with its
  own .sig signature over its name and SHA-256, checked against the built-in
  release key before unpacking.
- Changed update and restart notices: an open window's update notice clears
  automatically once the installed version overtakes it; mercury update and
  --rollback state that open windows keep their running version without naming
  one version and scope the no-daemon line to the current home; mercury daemon
  restart states both the installed and running versions.
- Changed how subscription sign-ins (ChatGPT, Google, Kimi, Hugging Face,
  Grok) refresh when several windows or profiles share one: one window
  refreshes and the others wait for it. A sign-in the provider refuses stays
  listed as expired, and can be removed with mercury auth logout <family>,
  instead of disappearing.
- Changed Kimi and Hugging Face turns that fall back to a stored API key after
  an expired sign-in to announce in the chat that the turn runs on and is
  billed to the stored key and how to reconnect.
- Changed OpenRouter's browser sign-in to listen on a free local port instead
  of a fixed one, label the minted key, open the browser address once, and
  respect cancellation.
- Changed copying a sign-in address with c in /logins and on the Logins/Keys
  page: it says Copied to clipboard only when the clipboard took the address.
  Otherwise it says so, a second c shows the address alone on one line, so the
  terminal can select or open it whole, and Enter returns. On the Logins/Keys
  page a drag across the address copies all of it, and a window too small for
  the detail pane shows the waiting sign-in, where it showed none of it
  before.
- Changed the /logins row in the command list to begin its list of providers
  with Anthropic in place of Claude subscription.
- Changed the Computer tool on large windows whose accessibility tree stops
  early: tree, find and fields now say where the tree stopped, a single match
  by name returns its ref instead of refusing outright, acts and root by ref
  run on a partial tree while the row still matches, and nearest-match
  refusals stay inside the web area when one is present.
- Changed Computer sequences and focusApp: a sequence with pixel coordinates
  after a screenshot taken in the same sequence is refused before any step
  runs, settleMs is waited out before taking the one end observation, and
  focusApp does nothing when the target application is already in front.
- Changed Computer acts that capture, focusApp and sequence screenshot steps
  to accept pixels: true when you want a pixel screenshot of a frontmost
  terminal instead of its text.
- Changed what the Browser tool answers when it cannot find or reach its
  target. A waitFor, an extract or an act that misses says what stood there
  instead: an element that is present but hidden and what hides it, the child
  frame or shadow root that holds it with the selector that reaches it, or a
  layer that covers most of the page. A click on a target under a cover that
  is on its way out waits and clicks at the first clear look, and a refused
  click says how long the cover was watched.
- Changed what the Browser tool says when the machine is not ready for its
  browser. On Linux, a browser that cannot start because shared libraries are
  missing names them and, on Debian and Ubuntu, the apt-get install line that
  adds them, and /browser install without unzip names it the same way. On
  every platform /browser install clears an empty build folder that a failed
  download left and refuses a partial build with the /browser remove line that
  clears it.
- Changed patience labels in /config, settings schema and docs from "quiet" to
  "silent" and "stream idle".
- Changed a key bound to a command that does not exist to show the Unknown
  command line; it did nothing before.
- Fixed a file deny rule on Windows not being applied to some Bash commands.
- Fixed a session resumed after a compaction losing the result of a tool call
  that had run in parallel with others.
- Fixed one of two crewmates (or tool calls) started from the same message
  going missing from the transcript when the second answered first.
- Fixed a session file over 5 MB showing fewer rows of a conversation than the
  same conversation in a smaller file, and a transcript holding a very long
  unbroken run of notices failing to open.
- Fixed a session resumed after a compaction opening at a tool result that had
  landed after the fold, with the summary and the reply after it missing.
  mercury -c, --resume by id or by file, the session picker's preview, a
  crewmate's resume and an editor's session load now open at the same end of
  the conversation, in session files over 5 MB too.
- Fixed /compact sent while a turn is running leaving its row at the end of
  the transcript after the fold. It now stands once where it ran and leaves
  the same conversation as an idle /compact.
- Fixed the Bash tool misreading exit code 1 when a command ends in grep, diff
  or a similar lookup.
- Fixed stale errors from the half-renamed state reaching the model after a
  TypeScript rename across files.
- Fixed a running tool row missing its timestamp and [Mercury] tag and jumping
  when an earlier tool call settles.
- Fixed an open pop-up keeping a stale height instead of refitting on the
  first frame when the area under the chat pane changes height.
- Fixed prompts with multiple pasted images numbering both attachment rows as
  [Image #1].
- Fixed Gemini models on an exact listed row (such as Gemini 4 Hydrogen)
  showing their raw model id instead of the live catalogue's display name, and
  fixed the status row redrawing when the Gemini catalogue lands.
- Fixed the prompts panel losing a prompt picked with ↑ or an open
  saved-prompt draft and cursor position when narrowing the window into the
  compact layout and widening back, and fixed /workbench reclaiming its pop-up
  after narrowing.
- Fixed /diff opening a file or hunk at its end instead of its top, and fixed
  labelled options in select cards getting clipped instead of wrapping inside
  the card width.
- Fixed words typed while a permission card is waiting losing the cursor at
  their end.
- Fixed a continued session losing its scratchpad directory on session switch.
- Fixed a command's answer in the chat dropping the backslash before a dot or
  other punctuation, which made a Windows path it printed wrong.
- Fixed mercury install --dry-run creating a config file or leaving a Node
  compile cache behind across the POSIX, .cmd, .ps1 and mercury.exe launchers.
- Fixed the last line mercury install prints naming mercury update --check,
  which only checks, as the command that keeps an install current: it names
  mercury update.
- Fixed Windows .cmd and .ps1 launchers writing terminal-reset escape
  sequences on non-zero exit when stdout is redirected to a file (such as
  mercury health --json > file).
- Fixed Browser child-frame lookups stalling for minutes on unresponsive
  frames (child frames are now checked in parallel with a 1-second limit
  each), text clicks inside an enclosing control being refused as covered by
  its own button, text extraction duplicating or including hidden shadow-root
  text, redirect notices warning "acts there will ask" on an already-approved
  origin, and attached-browser permission cards opening with the headless
  Chrome description.
- Fixed a headless run interrupted with Ctrl+C while the Browser tool had a
  browser open ending without its interrupted outcome row and without running
  the session.end hook.
- Fixed the Computer tool's file act misreporting "the file dialog is still
  open" on pages that already show a dialog (it now tracks only dialogs opened
  after its click).
- Fixed launching a team's fifth crewmate in the same message as its captain
  being refused for lacking a captain.
- Fixed Sleep waits over 300 s inside a crewmate refusing with advice about
  the Concourse switchboard instead of crewmate-specific guidance.
- Fixed cold-start blender --version checks timing out at 5 s (now waits 30
  s).
- Fixed the scheduler board in the classic layout showing no empty-state text
  when no schedules exist.
- Fixed the home screen selection moving out of bounds when the terminal
  shrinks.
- Fixed ten stale instructions and links in the bundled image-generation,
  provider-apis and research skills.
