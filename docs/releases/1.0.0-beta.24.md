# 1.0.0-beta.24 — ready for the tag

**State:** ready for the tag. This release is a fix update: ten more tools
ride in full on every cloud model from the first request, LSP is on wherever a
language server is reachable, and nothing is trimmed to fit a size limit; the
advisor answers real questions with words and says so when it has nothing; a
hosted connection that goes silent after its headers is noticed and retried,
and a reply cut mid-stream is reissued instead of ending the turn; Kimi's K2
coding model defers its tools; a new session on an OpenAI model reads the
shared prompt from the provider's cache; a headless session that repeats a
failing tool call stops and says why; a long image-heavy session is never
refused for its images; the session lists leave out the open conversation,
every model picker saves the full id, typing after a pasted image keeps its
order, a session started with a slash command is named after its first real
prompt, the background board is the runs board, a monitor's delivery is a
muted row, and a prompt that quotes command markup draws as the operator's
row; JevEval takes a file or a table; a parked session taken back warm starts
from its own record; the mock limit warnings speak per model; the copy receipt
on Linux is a whole sentence; a teammate's report wakes a background lead, a
stopped teammate keeps its transcript and resumes on a message, a working
teammate reads busy, and a failed one never comes back as live; Claude Sonnet
5.5 joins the catalogue as the sonnet family's newest, Sonnet 5 is priced at
the vendor's standard tier, and a new session starts on any Claude model the
account can run before its catalogue row lands.

**Verdict:** the hosted gate run on this release's published tree, and the
gate-ledger row whose code tree equals the tag's, are named on the published
form of this page. The local pool and the terminal-drives census ran on the
same line; their readings are recorded with the gate verdicts in the release's
records.

## What changed

- Added ten more tools loaded in full on every cloud model from the first
  request: ChangeSet, AstSearch, AstEdit, LSP, Test, Git, Debug, Monitor,
  Checkpoint and Rewind ride beside the tools already loaded instead of
  waiting in the deferred drawer, LSP is on wherever a language server is
  reachable — headless and daemon sessions included — and each of the ten says
  when to choose it over the usual tool; a local model's tool set is exactly
  as it was
- Fixed the first request being held under a size ceiling: its size is
  reported, never bounded, a connected MCP server's tool descriptions and
  schemas reach the model whole, and nothing is trimmed to fit a limit
- Fixed the advisor spending its whole budget thinking and answering with no
  text: its call has the model's own output ceiling and no clock of its own,
  an empty answer is asked for once more, and when the advisor still has
  nothing the chat shows a muted [advisor] row saying so instead of silence
- Fixed a hosted connection that sends its headers and then nothing being
  waited on to the ceiling: on every hosted provider the wait for the first
  byte is sized to the prompt and named in the notice, a dead connection is
  noticed sooner and retried, and a thinking model is never cut
- Fixed a reply cut mid-stream over HTTP/2 ending the turn on a raw error: it
  is the cut connection it is — the stream-cut notice shows, and the reply is
  reissued once on a fresh connection
- Added tool deferral on Kimi's K2 coding model: a request carries only the
  tools it needs, and a newly opened tool joins without disturbing the prompt
  cache, as on K3
- Fixed a new session on an OpenAI model reading nothing from the provider's
  prompt cache: it now reads the tools and system prompt it shares with the
  project's other sessions from the cache — 87.8% of a new session's first
  request, from 7.7% — because the cache key no longer changes with the
  conversation or the session
- Added a stop for a headless session repeating a tool call that fails the
  same way: after eight identical failures in a row the turn ends and says
  why, with no clock and no token count
- Fixed a long image-heavy session being refused once it holds more than
  twenty images: every image is sized to the API's limit when the request is
  composed, the refusal names the case, and a session refused before carries
  on at its next send, across a model switch, with no /clear
- Fixed the session lists naming the conversation that is already open: after
  a direct resume the rail's recent sessions, the session tabs and /sessions
  leave it out
- Fixed a model choice being saved as a family word: every model picker shows
  each model's full id and saves the id it shows, and a family word already
  saved keeps resolving as before
- Fixed typing after a pasted image putting the letters out of order: the
  cursor ends after every letter typed
- Fixed a session started with a slash command carrying the command's markup
  as its name: the view header, the sessions strip and /sessions name it after
  its first real prompt
- Fixed the background board's name: it is the runs board, its title reads
  runs, /runs opens it and /tasks still does
- Fixed text a monitor delivers into the chat drawing as a command row or not
  at all: it is always a muted [Monitor]: row, whatever markup it carries
- Fixed a prompt that quotes command markup drawing as another row or not at
  all: it draws as the operator's row, however long it is, so a long pasted
  prompt is never skipped in the chat
- Added JevEval taking a file or a table of evidence directly: a file path — a
  table becomes one item per row under the header's names, a text file one
  item — or an inline table, instead of pasting every item; the size rule is
  stated in the tool and refuses plainly above it, never trims
- Fixed a session taken back on a warm runner carrying prompt sections it
  never had: a resumed session's prompt is exactly its own record's, or the
  live world's when it has no record
- Fixed the opus-warning and sonnet-warning mock scenarios warning no one:
  /mock-limits opus-warning warns an Opus model of the Opus limit and
  sonnet-warning a Sonnet model of the Sonnet limit, in that model's own
  words, and no other model
- Fixed the copy receipt on Linux and over SSH being cut mid-sentence beside
  the way-back hint: it reads as a whole sentence at every width, says how the
  copy went, and shows that way's advice only where the row has room; the
  macOS receipt is unchanged
- Fixed a teammate's report not waking a background lead: a message to a lead
  idle between turns starts a turn for it the way a task notification does, in
  the background session shape too
- Fixed a teammate stopped from the crew view losing its transcript: r on its
  row continues it from where it was, its work before the stop in its context,
  under a new row with the same name
- Fixed a message to a teammate that was stopped or had ended being refused:
  SendMessage resumes it from its transcript with the message as its next
  turn, under the same name; a teammate that failed stays refused, never
  started again to carry the message
- Fixed the team brief reading a working teammate as idle: a teammate mid-turn
  reads busy, and idle means waiting between turns
- Fixed a teammate that failed at its spawn or later coming back into the team
  roster as a live member: a failed teammate leaves the roster for good, and
  the team brief never lists it as working
- Added Claude Sonnet 5.5 to the catalogue: claude-sonnet-5-5, "Sonnet 5.5",
  the sonnet55 alias with its 1M twin, priced at the vendor's tier and named
  on the splash; sonnet — and a saved "model": "sonnet" — now means it, as
  opus means Opus 5.5, and Sonnet 5 and Sonnet 4.6 keep their own rows under
  it
- Fixed Claude Sonnet 5's price: its turns are priced at the vendor's standard
  $2 in, $10 out instead of the withdrawn $3 and $15, in the spend views and
  the picker's price string
- Fixed a new session on a Claude model the account can run being refused
  before its catalogue row lands: it starts from every way in — the boot face,
  /clear, --model, a saved setting, the crew, workflow and advisor picks — the
  way it does in the REPL, the wire deciding, and stays so for future
  Anthropic models
- Fixed the npm package's repository address: mercury-tech-cli names
  github.com/Whq02/MercuryCLI in the form npm reads
- Fixed a daemon older than the deployed build deciding for a new session:
  when the deployed build moves under a running daemon, new sessions are born
  on the new build while everything live keeps running
