**Why it never published.** The release workflow builds the archives and then
runs a bridge gate: the previous shipped version must be able to read the new
archive. On a first release there is no previous version and the gate settles
as "nothing to bridge from" — but it looks releases up at the repository
address baked into the tree, and that address still named the pre-release
repository, which the release home's token cannot see. It read "not found"
where an empty list would have passed. The fix was the address, which is also
what the app's own update check reads; that fix, with the version bump and its
release notes, is 1.0.0-beta.2.
