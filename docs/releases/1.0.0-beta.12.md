**What shipped** (the bundled changelog is the one source; `/release-notes`
prints it):

1. **The Git tool finds the repository.** It takes a folder, finds the
   repository above it or the one directly below it, and names the folder
   when it refuses; a session opened on a folder above its repository is no
   longer refused with "not a git repository".
2. **Images on the OpenAI route.** The pre-send check follows the provider's
   own rule per image and per request, in words that name it; an image the
   provider refused leaves every later request, including after a resume.
3. **A restarted runner says why.** The notice for an agent stopped by a
   runner restart names the reason: after a crash, a settings change or a
   relaunch.
4. **The context overflow on a model switch.** The switch card counts the
   conversation against the target's window and compacts it first; the
   summary is written by a model whose window holds the history; the
   overflow notice carries Mercury's own count and the window.
5. **The queued line, hardened.** The 1.0.0-beta.11 fix is proved against
   every way a running sub-agent could take a line — two lines, a sleep, a
   crew notice, a sub-agent's own compaction, a nested call, a fork, a
   workflow's agent, the moment the Agent tool returns, a relaunch — and a
   second guard stands at the queue itself. Nothing visible changed.
6. **The doctor.** A health check is read-only: no global config save, no
   verify index, no counter; its daemon sign-in row no longer calls a
   catalogue timing gap a fault, and never asks for a daemon restart.
7. **A boot from a deleted folder** prints one plain line and exits, with no
   crash record and no crash notice on the next boot.
8. **The daemon's warm runner.** One runner is warmed per daemon boot and
   the first chat claims it; the throwaway spawn and retire are gone.
9. **A closed terminal.** The release-channel check's timeout is verified
   live, and shutdown writes nothing to a terminal that is gone. The stuck
   screen itself is not proved gone: the shutdown sequence did not block on
   a closed terminal even without the guard, and the evidence points at a
   screen paint; see the queue.
10. **Godot.** A running profile's scene tree is read over the engine
    debugger; a query during a capture or profile boot says what it is
    waiting for; the doctor warns on a retired Godot setting still set.
11. **Stopping a task that already finished.** The stop of a finished shell
    run names when it completed, its exit code and its output file, and is
    not an error.
12. **Teams that survive.** A teammate that dies at its first request is
    refused by name with the cause and leaves the roster; a team survives
    its lead's exit and restart; a workflow's failure line names the first
    failing agent and its cause.
13. **The OpenAI route after a reset and a sign-in again.** Delegated agents
    are no longer refused after a usage window reset and a re-login: the
    session follows the current sign-in's window and model list, and a
    refusal names the window alone.
14. **The account board's headers** name the family alone, with no
    "x/y signed in" count.

**Known gaps and the queue:** the stuck screen behind a closed terminal
(item 9) is not proved gone; the doctor's activity row no longer counts
headless health runs, since a health check is read-only; a team stays on
disk after any exit until it is deleted; the Agent tool's teammate answer
waits for the seat's first turn, bounded by that seat's own request patience.
Everything else queued is on [1.0.0-beta.13.md](1.0.0-beta.13.md).

**Not a product item**, one command on the owner's word: the nightly workspace
backup has failed since 2026-09-03 because its script is not deployed beside
the launcher (`scripts/ops/deploy-backup-agent.sh`).
