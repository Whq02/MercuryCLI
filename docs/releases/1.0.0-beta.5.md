**What shipped (the bundled changelog is the one source; `mercury /release-notes` prints it):** the model picker lists real models only, in the order OpenAI, Anthropic, OpenRouter, then the rest, and the sign-in list opens on the right row; a GPT reply cut off after a tool call no longer breaks every later request of the session, and a compaction whose summary the provider refused is reported once with the way out; the Edit tool's append and section modes and Eval cells that keep their state; a declared write scope for sibling worktrees, a reviewer agent on a frozen copy of a commit, and a message sent during a compaction held and delivered once; commands run from a session see your own environment; an internal configuration table and three inert environment variables removed; the checks Mercury runs on itself, sharpened.

**Ships in this tag**

1. **The model picker lists real models only** — `/model` shows the models
   your sign-ins can use, in the order OpenAI, Anthropic, OpenRouter, then the
   rest; the "Recommended" row is gone; the inline switcher in the composer
   opens on the current model; the sign-in list opens on the row of the most
   recent sign-in, else the first row.
2. **A GPT session survives a cut reply** — a reply that ended after a tool
   call without its closing event no longer breaks every later request of the
   session (a call the turn never received is not replayed); a compaction
   whose summary request the provider refuses is reported once, with the way
   out, instead of being retried; the line shown while sub-agents still run
   says how to stop one.
3. **The Edit and Eval tools** — Edit gains an append mode and a section mode
   (no line arithmetic), reports every hunk's outcome when a batch is refused,
   and keys what it knows of a file to the file's content; Eval cells keep the
   bindings made before a throw, list every nested call's outcome when a cell
   fails, and can take a call's error as a value.
4. **Write scope and reviewers** — a directory declared with `--add-dir` (or
   `/add-dir`) joins the session's write scope for every writing tool, and a
   refusal names the scope and both ways to widen it; a built-in reviewer agent
   reads a copy of the tree frozen at the reviewed commit, runs the checks
   there, and writes only the review section of its report; a message sent
   while a compaction runs is held, says so, and is delivered once when the
   compaction lands.
5. **Your environment, not Mercury's** — commands run from a session see your
   own environment: Mercury's internal stamps are scrubbed at the shell, and
   the proof suites refuse to start under foreign ones.
6. **Removed** — an internal configuration table that no longer did anything
   (every switch it held now reads as the plain behaviour it always resolved
   to, and a check keeps that class of name from returning); the environment
   variables `MERCURY_IDLE_THRESHOLD_MINUTES`, `MERCURY_IDLE_TOKEN_THRESHOLD`
   and `MERCURY_AGENT_ID`, which had no effect.
7. **The checks Mercury runs on itself** — a tracked map of the generated
   files a commit must regenerate, an exit code reported per proof in every
   suite, a preflight for terminal captures, real cost accounting for agent
   fleets, a readable session state for outside observers; and a config write
   that waits about seven seconds for its lock instead of two, so eight
   concurrent writers on a slow disk all land.

**Still queued, not this tag:** the efficiency work for the next tag — an idle
cockpit that spends a share of a core, background workers alive past the last
prompt, the weight around every call, one tool per message, a frame stall and a
slow cold boot, the tool-failure rate — each fix checked by a small local
measurement before and after; a Windows session whose preserved thinking was
dropped while sub-agents ran; the seat ceiling as a setting; Linux arm64 and
Windows arm64 archives; the adviser tool; multiplayer; the design-tool bridges;
the response-length choice; the vendored shell.
