# 1.0.11 — ready for the tag

**State:** ready for the tag. Mercury's own tools reach further and its runs
hold steadier. Read, Edit, Write, Grep and Glob work on another machine over
ssh; an isolated worktree starts with its own copy of the dependencies; the
rule files other coding tools left in a project are read as they stand;
structural search and rewrite cover 57 languages; the built-in browser has
tabs, downloads, uploads and device emulation; Read queries JSON and SQLite;
the Git tool resolves conflict regions; and there is a Nix flake. Runs left
alone finish more often, an install keeps working after its first launch, and
on Windows the sign-in is sealed at rest and the Bash tool finds the programs
a model expects. Scripted orchestration is the crew's now: the Concourse
coordinator and the Workflow tool have left the product. Updating is
recommended for every install.

## What changed

- Added a way to run the Blender tool with no window: with Blender located and
  no bridge answering, a call runs one background Blender process and returns
  its exit status, its output and its whole traceback.
- Added script and argv to the Blender tool's python_run: it runs a script
  file in the project with its arguments.
- Added show to the Blender tool: python_run returns up to four pictures the
  run wrote with its answer, and render_still returns the frame it rendered.
- Added recoveries to a run's outcome: one entry each time Mercury asked the
  model again in an unattended run.
- Added wards to a turn's outcome: one entry for each built-in refusal that
  fired in the turn.
- Added sealing at rest for the sign-in on Windows: the credential store is
  kept under a key Windows protects for your account.
  MERCURY_CREDENTIAL_STORE=unseal writes it back in the clear.
- Added brace alternatives to the path patterns of permission rules.
- Added MERCURY_EDIT_FORM (plain or full), which sends the Edit tool to every
  model in one named form for a run.
- Added MERCURY_GREP_RANKED, which lets Grep rank files by the words of a
  description. It is off by default.
- Added forty-four verbs to the turn spinner.
- Added whole bodies and member lists to structural patterns in 21 languages:
  a body or a list written as one $$$ meta-variable holds its members, so
  public void $NAME($$$PARAMS) { $$$BODY } finds the public methods of Java
  and C#, void $NAME($$$PARAMS) { $$$BODY } the functions of C and C++, fn
  $NAME($$$PARAMS) $RET { $$$BODY } those of Zig, $SEL { $$$DECLS } a CSS rule
  and { $$$PAIRS } a JSON object. These patterns were refused or found
  nothing.
- Added Gemini 4 Hydrogen, priced at $1.50 a million input tokens, $7.50
  output and $0.075 cached, with its fourth thinking level: xhigh and max
  reach it, and the model list says efforts low · medium · high · xhigh where
  that holds.
- Added named tabs to the built-in browser: tab on every page operation,
  status lists them, close with tab closes one, and persist keeps one past the
  idle lease. A tab that an act opens is kept as popup, and a crashed tab says
  so and reloads in place.
- Added downloads to the built-in browser: a download an act starts is saved
  into the session scratchpad and named in the answer with its path, size,
  type and SHA-256, and download opens or clicks for a file, waits for a
  transfer or lists them.
- Added uploads to the built-in browser: upload sets local files on a file
  input, through a file chooser or onto a drop zone; each file meets Read's
  decision and the page its origin's approval.
- Added rules to AstEdit: several pattern and rewrite pairs are previewed and
  applied in one pass over each file's original text, identical edits counted
  once and conflicting overlaps refused before anything is written.
- Added jq queries to Read: a target written <path>#read?q=<filter> runs the
  filter over a JSON document or a JSONL stream with a bundled jq, so nothing
  needs installing. Results page by whole values, a JSONL page names the
  source lines of its values, a stream of any size pages from its first bytes,
  and one document can be about 120 MB. A query's answer does not count as
  reading the file, and a query that does not finish is ended after ten
  minutes.
- Added profiler summaries to Read for V8 CPU profiles and macOS sampling
  reports: the time each function accounts for, paged, with source pointers,
  and a comparison of two reports.
- Added read-only SQL queries and table pages to Read for SQLite databases,
  and the deletion of one row through Write: the target ends #delete, the card
  shows the whole row and names the tables and triggers through which other
  rows may change, and the answer counts the rows that did. A row change in a
  database is not checkpointed: the card and the answer say so and keep the
  row as it was.
- Added a worktree's own copies of what git ignores: an isolated worktree of a
  crewmate or of a session starts with its own copy-on-write copy of the
  checkout's dependency folders and of everything else git ignores (build
  output, caches, .env files) on APFS and on Linux filesystems with reflinks,
  so crewmates build and install side by side without touching the checkout or
  each other. A crewmate starts at once and its first tool call waits for its
  copy. Instruction files, what a Read deny rule names and Mercury's own
  folders stay behind. Elsewhere, and with MERCURY_WORKTREE_CLONE=off, the
  worktree holds links as before.
- Added files on another machine: Read, Edit, Write, Grep and Glob take
  ssh://host/path through your own ssh configuration, keys and agent, with
  nothing to set up. A page of a large file travels alone, an edit is checked
  against the remote file before it is written, and the ordinary permission
  rules apply (Read(ssh://web1/**)). Nothing is sent or started unless a path
  begins ssh://; ssh:// alone lists the hosts of your configuration. See
  docs/REMOTE-FILES.md.
- Added device and condition emulation to the built-in browser: viewport takes
  an emulation object (a device from the driver's catalogue that devices
  lists, or raw size, scale, mobile, touch and user agent; timezone, locale,
  CPU slowdown, network throttling and offline, geolocation, colour scheme,
  reduced motion, extra headers and basic credentials), kept by the page until
  reset. Extra headers go with every request the page makes, and basic
  credentials answer one origin. A screenshot says how its pixels map to CSS
  pixels.
- Added 34 languages to structural search and rewrite (AstSearch, AstEdit), 57
  in all: YAML, Markdown, SQL, Dockerfile, Lua, Make, CMake, XML, HCL,
  GraphQL, Protobuf, Dart, Scala, Elixir, Zig, Haskell, OCaml, Svelte, Astro,
  Nix, R, Julia, Starlark, Clojure, Erlang, Objective-C, Fortran, Solidity,
  Verilog, Emacs Lisp, just, Odin, TLA+ and diff. A grammar is loaded only
  when a search or a rewrite reaches a file of its language, and release
  archives carry all 57 with their licence texts.
- Added reading of the instruction and rule files other coding tools left in a
  project, as they stand and with no setup: AGENTS.md and the shared .agents
  folder, and the guides and rules of Claude Code, Gemini, Copilot, Cursor,
  Windsurf and Cline, with the folders COPILOT_CUSTOM_INSTRUCTIONS_DIRS names;
  the compatibility page names every file. A rule scoped to files reaches the
  model only when such a file is read, edited or searched. A MERCURY.md in or
  above the working directory still decides: with one, the others load only
  where it imports them. /memory files names each file, its tool and when it
  loads.
- Added a Nix flake: packages for Linux and macOS made from the signed release

  modules. A Mercury that Nix installed leaves installing and updating to its

- Added conflict regions to the Git tool: conflicts lists each conflict block

- Added prerequisites to the Git tool's commit groups: a group names the
