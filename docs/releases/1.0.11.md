# 1.0.11 — ready for the tag

**State:** ready for the tag. Runs left alone finish more often, and an
install keeps working after its first launch. An unattended run is asked once
when its model stops short, a run under a budget stops before a call it cannot
pay, and a session no longer hangs on a file that is not a file. The Blender
tool works with no window, Windows keeps the sign-in sealed at rest, and deny
rules, the Git tool and the safety floors apply more consistently. The
Concourse coordinator has left the product. Updating is recommended for every
install.

## What changed

- Added a way to run the Blender tool with no window: with Blender located and
  no bridge answering, a call runs one background Blender process and returns
  its exit status, its output and its whole traceback.
- Added script and argv to the Blender tool's python_run: it runs a script
  file in the project with its arguments.
- Added show to the Blender tool: python_run returns up to four pictures the
  run wrote with its answer, and render_still returns the frame it rendered.
- Added recoveries to a run's outcome: one entry each time Mercury asked the
  model again in an unattended run.
- Added wards to a turn's outcome: one entry for each built-in refusal that
  fired in the turn.
- Added sealing at rest for the sign-in on Windows: the credential store is
  kept under a key Windows protects for your account.
  MERCURY_CREDENTIAL_STORE=unseal writes it back in the clear.
- Added brace alternatives to the path patterns of permission rules.
- Added MERCURY_EDIT_FORM (plain or full), which sends the Edit tool to every
  model in one named form for a run.
- Added MERCURY_GREP_RANKED, which lets Grep rank files by the words of a
  description. It is off by default.
- Added forty-four verbs to the turn spinner.
- Added files on another machine: Read, Edit, Write, Grep and Glob take
  ssh://host/path through your own ssh configuration, keys and agent, with
  nothing to set up. A page of a large file travels alone, an edit is checked
  against the remote file before it is written, and the ordinary permission
  rules apply (Read(ssh://web1/**)). Nothing is sent or started unless a path
  begins ssh://; ssh:// alone lists the hosts of your configuration. See
  docs/REMOTE-FILES.md.
- Added device and condition emulation to the built-in browser: viewport takes
  an emulation object (a device from the driver's catalogue that devices
  lists, or raw size, scale, mobile, touch and user agent; timezone, locale,
  CPU slowdown, network throttling and offline, geolocation, colour scheme,
  reduced motion, extra headers and basic credentials), kept by the page until
  reset. Extra headers go with every request the page makes, and basic
  credentials answer one origin. A screenshot says how its pixels map to CSS
  pixels.
- Added 34 languages to structural search and rewrite (AstSearch, AstEdit), 57
  in all: YAML, Markdown, SQL, Dockerfile, Lua, Make, CMake, XML, HCL,
  GraphQL, Protobuf, Dart, Scala, Elixir, Zig, Haskell, OCaml, Svelte, Astro,
  Nix, R, Julia, Starlark, Clojure, Erlang, Objective-C, Fortran, Solidity,
  Verilog, Emacs Lisp, just, Odin, TLA+ and diff. A grammar is loaded only
  when a search or a rewrite reaches a file of its language, and release
  archives carry all 57 with their licence texts.
- Added reading of the instruction and rule files other coding tools left in a
  project, as they stand and with no setup: AGENTS.md and the shared .agents
  folder, and the guides and rules of Claude Code, Gemini, Copilot, Cursor,
  Windsurf and Cline, with the folders COPILOT_CUSTOM_INSTRUCTIONS_DIRS names;
  the compatibility page names every file. A rule scoped to files reaches the
  model only when such a file is read, edited or searched. A MERCURY.md in or
  above the working directory still decides: with one, the others load only
  where it imports them. /memory files names each file, its tool and when it
  loads.
- Added a Nix flake: packages for Linux and macOS made from the signed release
  archives, a development shell, an overlay, and Home Manager and NixOS
  modules. A Mercury that Nix installed leaves installing and updating to its
  flake or profile.
- Added conflict regions to the Git tool: conflicts lists each conflict block
  of an unmerged file, and resolve takes ours, theirs, base, both or given
  text for the regions it names, staging a file once its last region is
  resolved. A whole file can also be taken as base or as both.
- Added prerequisites to the Git tool's commit groups: a group names the
  groups it depends on, the plan orders them, and a reference to itself, to an
  unknown group or in a cycle is refused before anything is staged.
- Changed the Session Concourse to its two panes: the coordinator, the opt-in
  model that launched and steered sessions from the board, is gone with its
  pane, its tools and its settings rows. n on the board starts a session as
  before, --coordinator-on and --coordinator-off are still accepted and say so
  in one line, and a home that had it on keeps its settings and files.
- Changed an unattended run (mercury run, a runner with no screen, a crewmate)
  whose model says what it will do next and then ends its turn: it is asked
  once to take the step or give its final answer.
- Changed an unattended run whose model answers with no words and no tool
  call: it is asked once for its answer.
- Changed an unattended run whose model repeats itself again after the loop
  notice: the turn ends loop_stopped and the run exits 1.
- Changed a run under --budget: it does not start a model call whose input
  alone the budget cannot pay, and its outcome says so.
- Changed Read and the reopening of a session to open only regular files: a
  named pipe, a socket or a device is refused in one sentence, and a very
  large file is read in bounded memory.
- Changed Read's crop of an image: a box that passes the image's edge is cut
  to the image, and a whole-number scale enlarges the crop pixel for pixel.
- Changed the refusal of a detached start (nohup … &): it says when a
  background command ends, and names the Service tool where the session offers
  it.
- Changed the hook-wait line: it appears once a hook has been waited on for a
  second and goes when the hook ends.
- Changed the Blender tool to be offered wherever Blender is located, not only
  beside a .blend file. Reading the bridge's status writes nothing.
- Changed the boot menu: the rows for the Debug tool, the Godot control
  surface, Unity, Blender and Aseprite reach running sessions at their next
  turn, and the saved receipt names the rows that do.
- Changed deny rules: a file a deny rule covers is not named or opened by
  Grep, Glob, a Read of its folder, Inspect, the Git tool or the Blender and
  Aseprite tools, and a Read by reference is decided as a Read by path.
- Changed settings validation: a rule it cannot read is reported and stays in
  force.
- Changed the Git tool to check the revisions and paths it is given more
  strictly, on older versions of git as well.
- Changed the safety floors around Mercury's stored credentials and its own
  runtime: they read more forms of a shell line on macOS, Linux and Windows
  and refuse fewer ordinary commands. The trust page says what they do.
- Changed the terminal painter to redraw less of the screen at each frame.
- Changed a crewmate's launch that an interrupt hands to the background: it
  keeps its reservation until its run ends.
- Changed a hosted window: its model is given the harness map at its first
  turn.
- Changed a session's record: each turn writes a line when it begins.
- Changed /health to read the window of the focused session's model, and a
  local window of whole millions of tokens to read 1M.
- Changed the two side rails to name the sections their height dropped.
- Changed a question card to name the key bound to the external editor.
- Changed the external editor's value on Windows to be parsed by the system's
  own command-line rules.
- Changed TensorFold to 1.2.7 where Mercury names, fetches and verifies the
  engine; a model card's prompt-cache ceiling follows the engine's rule.
- Changed the tool descriptions, prompts and bundled skills a model reads:
  corrected against the product and shortened, by about a tenth where a
  session sends every tool's definition and by less where tools are loaded on
  demand.
- Changed the grammar engine to keep V8's optimising tier off while it parses
  with a grammar whose optimiser costs 400 MB or more of memory (Bash,
  PowerShell, Kotlin, Swift, Markdown, Objective-C, Fortran, Verilog, TLA+),
  so the process keeps its size; MERCURY_GRAMMAR_BASELINE=0 lets them reach
  it.
- Changed a conversation on a local TensorFold model to be resumed where the
  engine left it: every earlier reply goes back with the reasoning the model
  wrote, and on an engine of this machine that keeps prompt states and does
  not read ahead itself, Mercury reads the finished turn ahead between turns.
  A request of the session cancels the reading ahead and waits for the part
  already in flight. MERCURY_LOCAL_NEXT_TURN_PREFILL=0 turns it off.
- Changed llama.cpp to 1.0.0 (b12359) where Mercury installs it for the
  Windows TensorFold group and where a rented pod's engine image is built from
  it; a llama-server from b11829 on is still accepted.
- Changed the Git tool's commit plan to say on its card and in its receipt
  that pre-commit and commit-msg hooks are not run.
- Changed the Git tool's resolve to apply Edit deny rules to the files it
  writes, and its conflict list to leave out a file a Read deny rule covers
  and say how many it left out.
- Fixed a Homebrew install losing its mercury command after the first launch,
  where ~/.local/bin stands before Homebrew on PATH. An install already caught
  is mended by ln -sf "$(brew --prefix)/bin/mercury" ~/.local/bin/mercury.
- Fixed mercury install --uninstall on Windows stopping half way and leaving a
  command that could not run: the command and its PATH entry go, and the files
  in use are removed once the command has ended.
- Fixed a Gemini conversation that outgrew the model's window ending on the
  provider's refusal: the conversation is compacted and the request sent
  again.
- Fixed a reader losing their place in the transcript at a ctrl+o flip and
  when a streaming reply settles.
- Fixed a resumed session whose run ended inside a tool call: the call reads
  as answered, and the card says the session resumed with one failed call.
- Fixed a resumed session reading "the runner is starting" after its admission
  was refused.
- Fixed a hosted chat not telling the end of a short first turn sent while its
  runner was starting.
- Fixed a large paste followed at once by Enter or by typing losing text, and
  a stray paste marker attaching the clipboard's image.
- Fixed mercury health naming the install with the long-path prefix on
  Windows, and a daemon read as wedged from a stale answer.
- Fixed an export redacting ordinary words saved beside a sign-in.
- Fixed the screen going blank while a layout was not yet valid, a scroll box
  losing its background, and stale cells left under a moved overlay.
- Fixed the ctrl+c notice on the home screen and other full-screen pages
  showing the end of the row beneath it.
- Fixed a start with an argument, such as mercury --model <id>, erasing eight
  lines of what stood in the terminal before it.
- Fixed MERCURY_TOOL_DEFER_PROBE=1 doing nothing behind a gateway.
- Fixed an interrupted call of the Blender tool over its bridge, or of the
  Aseprite tool, running on until the tool answered: the call ends at once and
  the Aseprite process is stopped.
- Fixed a kill by name, such as pkill -f <pattern> 2>/dev/null, being refused
  when the command redirected its output.
- Fixed a malformed tool call that a GLM model left in its reply on TensorFold
  being run with corrupt arguments.
- Fixed /health reading the Blender tool as undeclared where it is offered.
- Fixed a resumed session's starting count running backwards, and a focus
  switched to a busy session keeping the last turn's tip.
- Fixed an approved project extension held off in an untrusted folder saying
  nothing.
- Fixed structural search and rewrite over a folder to apply Read deny rules
  to files reached through a link.
- Fixed a valid pattern being called malformed when the only file of its
  language was over the size limit.
- Fixed a one-shot mercury run ending without its report while a crewmate was
  parked waiting for its teammates, or between a background crewmate's end and
  its result.
- Fixed a personal MERCURY.md in Mercury's home keeping a project's AGENTS.md
  from loading.
- Fixed a session hanging at its start in a folder whose MERCURY.md, AGENTS.md
  or imported instruction file is a named pipe: the file is passed over.
- Fixed a tool loaded through ToolSearch failing the turn on a llama.cpp
  server added in /llmhost or rented as a pod (HTTP 500, System message must
  be at the beginning): the tool joins the request's own tool list.
- Fixed a tool loaded through ToolSearch being refused, or never defined to
  the model, on a vLLM or SGLang server whose chat template takes no system
  message after the first (Qwen3.8, Mistral Large 3, MiniMax-M3, Beam-1.0,
  gpt-oss-120b).
- Fixed a llama.cpp 1.0.0 server's origin rule being reported as a rejected
  key: the message names the --cors-origins entry to start the server with.
- Fixed thinking switched off having no effect on a llama.cpp server.
