**Known gaps**

- No Intel Mac build: the archives are Apple silicon, Linux x64 and Windows
  x64. The installers say so on an Intel Mac and point at building from source.
- `mercury update` reads releases through the user's own signed-in GitHub CLI;
  a user without `gh` reinstalls by rerunning the install command.
- `LICENSE.md` carries the draft banner and five blanks (version, release date,
  change date, the companion terms' hash, the commercial contact); the companion
  production terms and the trademark policy are not in the tree.
- The real-terminal drive suites are an advisory verdict and were not run for
  this tag; the release verdict is the deterministic set.
- The archives shipped UNSIGNED: the hosted release workflow never held the
  signing key, and nothing stopped the publish. Every interactive launch of
  this version prints `mercury: provenance — unsigned …`; `mercury doctor`
  shows the same verdict. 1.0.0-beta.3 signs every archive, verifies it before
  publishing, and says "unsigned" once per install (docs/TRUST.md).
