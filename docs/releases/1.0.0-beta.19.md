# 1.0.0-beta.19 — ready for the tag

**State:** ready for the tag. This release makes the Anthropic model list
live: the picker reads every signed-in account's models from the provider,
a new model is there the day it ships, and a refused model says why.
Settings, usage and status open as popups, a panel closes on a click
outside it, a burst of tool calls is one card that counts up, and a
scheduled wake arrives as its own muted row. Esc on a hung tool call ends
that call alone, a restart keeps its running agents, token counts are one
number everywhere, and the Windows build is fixed at its faults.

**Verdict:** hosted gate run 35972357796 reads the 135 release suites on the
release line's published tree (commit 148ad6ebb) as this page is written; the
gate-ledger row whose code tree equals the tag's names the release-tip gate
on the published form of this page. The local pool read 133 of 135 suites green on the wave-3 tip beneath, its two reds fixed forward before the tag. The
terminal drives, an advisory class, run as run 35959551520 beside it; that
run's reading is recorded on the 1.0.0-beta.20 page.

## What changed

- Added a live Anthropic model list. New models show up in the picker when
  they ship. Same for every provider
- Added a reason when a model is refused, on its picker row and in the doctor
- Added /view on and /view off for the sessions bar. Off by default
- Added a counting card for bursts of tool calls
- Added usage warnings at 80 and 90 percent for subscriptions that report one.
  Warnings only
- Changed /config, /usage and /status into popups
- Changed panels that close on esc to also close on a click outside
- Changed the logins card to fetch the lists it shows
- Changed scheduled wakes to show as muted rows
- Changed esc on a hung tool call to end only that call
- Changed a session restart to keep its running agents and the queued line
- Changed held notices and queued messages to appear in order
- Changed bare skill names to print their usage instead of starting a turn
- Changed the Browser tool to use its own browser instead of yours
- Fixed workflow runs filed under the wrong project after a cd
- Fixed a session dying when a background agent finished in a removed worktree
- Fixed Windows: paths, encodings, process trees, the credential store,
  watchers, the updater
