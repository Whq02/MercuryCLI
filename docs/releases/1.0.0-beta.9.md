# 1.0.0-beta.9 — queued

**State:** queued behind 1.0.0-beta.8. This page names the headline items
lined up for it and what stays queued after it; the verdict, the tag commit
and the publish line are written at the tag.

**Planned for this tag — Mercury working on itself.** The defects Mercury
showed while it built 1.0.0-beta.6 with its own agents, fixed where they live:

1. **Notices that are read** — Added a ledger of unread notices: an agent
   waiting on a completion it never saw is nudged instead of stalling. Every
   notice delivered to an agent of a session is recorded until a turn of that
   agent reads it; the session facts carry the ledger and the Crew view shows
   each sub-agent's unread count; an agent idle past
   `MERCURY_NOTICE_DEADLINE_MS` (three minutes unset) is woken with the
   notices it missed, once per notice, and a notice whose agent is gone is
   retired with a row saying so.
2. **A scan mode** — a read manifest an agent must honour before it reports,
   and a sweep agent type built on it.
3. **The provider gate** — the delegation latches and an expired sign-in
   reported as what it is, never as an exhausted usage window.
4. **Teams that survive** — a teammate reported running after dying at spawn,
   a team lost on restart, a workflow failure line carrying the first agent's
   cause.
5. **The OpenAI route's tool calls** — empty placeholders stripped at the
   decode for every tool, the quote normalisation, an Edit refusal naming the
   read lines.
6. **The worker count** — the daemon's own count of live workers, taken out of
   1.0.0-beta.6, revisited as a clearly explained proposal.
7. The items that ride along: a line sent while the model works — it already
   reached the model at the next tool boundary, and when an interrupt lands;
   it is now introduced in Mercury's words with what it means for the active
   task, and its row lands with the clock it was sent at; the wider Edit and paste
   sharpenings; computer use's structured ask and global stop chord; a
   resource governor the session shows its agents; generated assets
   registered by their generators; tools offered only where they can work.
8. **A woken session keeps its preserved thinking.** Fixed a woken session
   dropping its preserved thinking: the history is sent byte for byte after a
   revive, and the prefix record survives it. A computer-tool screenshot is
   read back from its file on resume instead of the stub the session file
   keeps, and the prefix ledger's record lives beside the session so a fresh
   process names the part that moved instead of "a client-side edit".
   Moved the preserved-thinking record's write off the request path; the
   record lives and dies with its session: written in the background once
   the request is on the wire, removed with the row from the board or with a
   pruned transcript, and swept at boot when its transcript is gone or it is
   older than `MERCURY_PREFIX_RECORD_RETENTION_DAYS` (thirty days unset).

9. **Refactors through the language service.** Added refactors through the
   language service: rename a symbol or move a file with every reference
   rewritten, previewed as data before it is applied. The LSP tool's
   `rename` refuses a rename that would collide with or capture another
   symbol, `moveSymbol` moves a declaration to another file with the
   imports rewritten, `codeActions` takes a kind (organise imports, add
   missing imports, refactors), and every write is a dry run first — the
   edits as data and a plan token — then an apply that honours the
   read-before-edit law. The page is [LANGUAGE-SERVICE.md](../LANGUAGE-SERVICE.md).

10. Changed the generated-asset map to be written by the generators
   themselves: each registers its row when it runs (`--register` writes the
   row alone), and the commit gate's census refuses a tracked file that
   declares a generator without a row.
11. Changed the catalog to withhold a tool whose machine dependency is
   absent — the Debug tool with no reachable adapter, the Godot tool with
   no Godot executable, beside the Computer tool with no driver — and the
   doctor's `Tools withheld` row names each with why and the remedy.
12. Added the box's state to what a session shows its agents: the session
   facts carry a `box` row with the load, the memory available, the box
   lock's holders and waiters, and the memory guard's verdict; an agent
   reads it as `mercury://health/box`, and a shell command that waited on
   the lock says so in its result. Nothing is scheduled or throttled by it.
13. Added the session's scratchpad to the model's prompt as the place for
   temporary files; it lies outside the project, the turn receipt counts
   edits there as scratchpad edits and nowhere else, and it is swept when
   the session ends.
