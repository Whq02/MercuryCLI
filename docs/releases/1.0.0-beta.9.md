**What shipped (the bundled changelog is the one source; `mercury /release-notes` prints it):** a woken session keeps its preserved thinking; a new sign-in reaches the open chats; the cockpit keeps its rail and follows the window on Windows; a ledger of unread notices; refactors through the language service; Godot captures, profiles and a bridge per instance; tools withheld where they cannot work; the box's state and the scratchpad in the prompt.

**Ships in this tag** — Mercury working on itself: the defects it showed while
it built itself with its own agents, fixed where they live, and the Godot
tooling its Windows session asked for.

1. **Notices that are read** — Added a ledger of unread notices: an agent
   waiting on a completion it never saw is nudged instead of stalling. Every
   notice delivered to an agent of a session is recorded until a turn of that
   agent reads it; the session facts carry the ledger and the Crew view shows
   each sub-agent's unread count; an agent idle past
   `MERCURY_NOTICE_DEADLINE_MS` (three minutes unset) is woken with the
   notices it missed, once per notice, and a notice whose agent is gone is
   retired with a row saying so.
2. **A sign-in reaches the open chats.** A new sign-in reaches the engines
   behind the open chats — the daemon tells every runner it hosts to read the
   account again — so a delegated agent is never refused with a departed
   account's usage window; a refusal names the account the window belongs to
   and when it was seen, and a runner that missed the word trusts a limit
   verdict only for the account that observed it.
3. **The chat.** A line sent while the model works already reached the model
   at the next tool boundary; it is now introduced in Mercury's words with
   what it means for the active task, and its row lands with the clock it was
   sent at. A task notification the chat has already shown is shown once, not
   redrawn under every new message until it ages out.

4. **A woken session keeps its preserved thinking.** Fixed a woken session
   dropping its preserved thinking: the history is sent byte for byte after a
   revive, and the prefix record survives it. A computer-tool screenshot is
   read back from its file on resume instead of the stub the session file
   keeps, and the prefix ledger's record lives beside the session so a fresh
   process names the part that moved instead of "a client-side edit".
   Moved the preserved-thinking record's write off the request path; the
   record lives and dies with its session: written in the background once
   the request is on the wire, removed with the row from the board or with a
   pruned transcript, and swept at boot when its transcript is gone or it is
   older than `MERCURY_PREFIX_RECORD_RETENTION_DAYS` (thirty days unset).

5. **Refactors through the language service.** Added refactors through the
   language service: rename a symbol or move a file with every reference
   rewritten, previewed as data before it is applied. The LSP tool's
   `rename` refuses a rename that would collide with or capture another
   symbol, `moveSymbol` moves a declaration to another file with the
   imports rewritten, `codeActions` takes a kind (organise imports, add
   missing imports, refactors), and every write is a dry run first — the
   edits as data and a plan token — then an apply that honours the
   read-before-edit law. The page is [LANGUAGE-SERVICE.md](../LANGUAGE-SERVICE.md).

6. Changed the generated-asset map to be written by the generators
   themselves: each registers its row when it runs (`--register` writes the
   row alone), and the commit gate's census refuses a tracked file that
   declares a generator without a row.
7. Changed the catalog to withhold a tool whose machine dependency is
   absent — the Debug tool with no reachable adapter, the Godot tool with
   no Godot executable, beside the Computer tool with no driver — and the
   doctor's `Tools withheld` row names each with why and the remedy. The
   catalog build spawns nothing for it: the toolchain probes run once per
   process in the background and the catalog reads their memo.
8. Added the box's state to what a session shows its agents: the session
   facts carry a `box` row with the load, the memory available (the last
   sample, with its clock — an answer never takes one), the box
   lock's holders and waiters, and the memory guard's verdict; an agent
   reads it as `mercury://health/box`, and a shell command that waited on
   the lock says so in its result. Nothing is scheduled or throttled by it.
9. Added the session's scratchpad to the model's prompt as the place for
   temporary files; it lies outside the project, the turn receipt counts
   edits there as scratchpad edits and nowhere else, and it is swept when
   the session ends.
10. **Godot engine jobs, instances and gates.** Added Godot captures, frame
   statistics and settled profiles as engine jobs: off-screen on a frozen
   copy of the project, the frozen clock values and seeds handed to the
   project's own hooks and acknowledged in the result, frames under the
   run's own directory, a quiet-machine guard on every profile; and a
   bridge per Godot instance with its own port and token, a runtime query
   surface, file leases without a team, and a proof-drift check on every
   gate. Added the engine's own profiler to Godot profile jobs over the
   debugger protocol, headless, beside the project's tables. The page is
   [VULCAN-GODOT-TOOLS.md](../VULCAN-GODOT-TOOLS.md).

**Known gaps in this tag**

- Apple Terminal on macOS 15 and older has no 24-bit colour; the mascot and
  the previews misread their colours there. Queued for 1.0.0-beta.10.
- The update notice names `mercury update` for every install; a brew or npm
  install updates through its own tool.
- The Boot face losing its mascot head on Windows after a long session did
  not reproduce on macOS and stays open.
