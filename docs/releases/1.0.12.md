# 1.0.12 — ready for the tag

**State:** ready for the tag. Mercury 1.0.12 adds GPT-6.2 Astra, GPT-6.2 Sol,
Gemini 4 Neon and Qwen4 Max, ships GNU bash 5.3.20 on every platform so the
Bash tool never runs a command in zsh, and reduces the Boot face to five
actions. Manual /compact says why it refuses, permission cards name who is
asking, and sign-outs and unreadable files fail plainly. Updating is
recommended for every install.

## What changed

- Added GPT-6.2 Astra and GPT-6.2 Sol to the model picker with their windows,
  output ceilings and prices; both are also on OpenCode Zen and in the Nous
  Portal list.
- Added Gemini 4 Neon's price, output ceiling and thinking levels; with a
  Gemini API key the effort dial runs from low to xhigh.
- Added Qwen4 Max (qwen4-max) with its window, output ceiling, effort levels
  and prices; bare qwen4* ids route to Qwen.
- Added GNU bash 5.3.20 to the macOS, Linux and Windows archives, under the
  GNU General Public License, version 3 or later; the licence texts and a note
  naming the sources ride beside the binaries at vendor/bash/<platform>/.
- Added a debug-log line for OpenAI requests that lists the input items the
  provider withheld, with the reason for each.
- Added a debug-log line that records used heap memory at each 500 MB step.
- Added models to the close row of a mercury runner session: the model calls
  that wrote the note for the next session, each with its cost.
- Added used-share meters to the Gemini plan quota rows on the usage screen.
- Added a note to the /rewind list and confirm card: it counts the later shell
  commands that could have changed files and says their changes are not put
  back.
- Added the asking crewmate's name to permission cards.
- Changed the Boot face to five actions: New Session, Continue Last Session,
  Logins/Keys, Session Manager (Concourse) and Boot Menu. MCPs & Skills and
  Agents open from Boot Menu, and Continue Last Session can be chosen when the
  last session belongs to another project.
- Changed the Logins/Keys and Boot Menu screens: states read as plain words
  (no key, not signed in), long lines wrap to the pane, and full provider
  labels fit on narrow terminals.
- Changed the model a new session starts on after an OpenAI sign-in: the Sol
  of the newest GPT release the account serves, and never a specialised,
  premium or deprecated model while the account serves a general one.
- Changed the head rows of the Nous Portal list to GPT-6.2 Astra and GPT-6.2
  Sol.
- Changed the /model receipt when a new default replaces another: it names the
  default it replaced.
- Changed the OpenAI lines of /caching to today's lifetimes and rates.
- Changed when a session compacts on GPT models whose input maximum is below
  their window: at 879,000 tokens under a 922,000-token maximum, where it
  compacted at 1,007,000, and at 229,000 under a 272,000-token maximum, where
  it compacted at 357,000. The gauge's share and three size messages follow
  the input limit; a window stated in your settings moves the gauge, not that
  point.
- Changed /compact: queued while a turn runs, it runs at the next step; a
  manual compaction that would not shrink the conversation is refused with its
  cause and no leading Error:.
- Changed the cost shown for GPT-5.6 Sol with an OpenAI API key to follow the
  end of its promotional price on 30 November 2026.
- Changed the shell the Bash tool runs on macOS and Linux: the GNU bash 5.3.20
  Mercury ships, whatever your login shell; the system's bash and then the
  bundled engine serve when it cannot start. No command runs in zsh.
- Changed what a command starts from on macOS and Linux: the environment
  Mercury was started with, the aliases, functions and options your bash login
  files define, and what your login shell's files export, read once a session.
  The first Bash result says when nothing could be carried and what to change.
  Aliases and functions written in ~/.zshrc no longer reach a command.
- Changed git in tool shells on Windows so a command does not stall on a
  credential window.
- Changed the PowerShell tool so cd - cannot jump back to an earlier folder.
- Changed the session's shell line on every platform to name the shell that
  runs and its version.
- Changed three questions the Bash tool asked before running a command (~[, a
  word that begins with =, a zsh module builtin): such a command is read like
  any other, and zsh -c '…' is asked about as a program whose script Mercury
  does not read.
- Changed the shell the Bash tool runs on Windows: an installed bash 5 serves
  first, otherwise the bash Mercury ships; the bundled engine serves only when
  no bash starts or you choose it (MERCURY_SHELL_ENGINE=brush).
- Changed MERCURY_SHELL_ENGINE=system on Windows to mean a bash and never the
  engine.
- Changed MERCURY_GIT_BASH_PATH: the program it names serves first when it
  answers as a bash; one that does not is passed over, and the first Bash call
  says why.
- Changed the health check's Bash tool shell row: it names the shell that
  runs, its version and source and what was passed over, and warns when the
  install carries no bash pack.
- Changed the safety floors, delete wards and Flow checks to read more shell
  forms (brace lists, parameter expansions, curl -T, OLDPWD, cd inside eval,
  aliases or functions) and more Windows homes and roots.
- Changed permission cards: an outside-project option shows the full folder
  path, and options that would grant nothing are omitted.
- Changed sign-out and key sign-in: a credential file that cannot be read or
  written is never overwritten, a damaged auth file is moved aside, and a
  sign-out that cannot remove a credential names the store and exits 1.
- Changed unreadable files and failed actions across screens and the CLI to
  show a plain error where they showed an empty list.
- Changed handoff notes and /orient: a note holds only what its session did or
  saw and is framed with its age, and /orient no longer repeats Mercury's own
  rules in MERCURY.md.
- Changed the /sessions picker: titles match Session Manager (Concourse), and
  Left and Right scroll the session strip.
- Changed mercury update --check on a non-managed install to print the this
  Mercury: line; a source checkout resolves to its root.
- Changed three small wordings: the ? list reads ! for shell mode and names
  the mode cycle, the exit notice reads press ctrl+c again, and the first-byte
  wait line reads gives up after ….
- Changed background command notice rows without output to omit the count of
  their metadata lines.
- Changed the session runner's heap ceiling on Node to a quarter of the
  machine's memory, up to 16,384 MB, unless NODE_OPTIONS sets it.
- Changed Read's caption OCR on images and PDF pages to time out after 3
  seconds.
- Changed retries: a rate limit is reported at once and retried up to
  MERCURY_MAX_RETRIES times with OpenAI, OpenAI-compatible and Z.ai providers.
- Changed the built-in browser to launch Chrome with
  --disable-component-update.
- Changed stdio MCP servers on Windows to fail before spawn when the command
  is missing.
- Changed the trace: a tool call cut before it began leaves no line in
  mercury-trace.jsonl.
- Changed answers on the runner's wire: refusals of project/query and
  agent/resume answer -32010 and malformed parameters -32602, where they
  answered the internal error -32603; both SDKs raise MercuryRefusal for a
  refusal.
- Changed mercury run started with MERCURY_CONCOURSE_WORKER=1 and no session
  named: it ends with exit 2 and one sentence on stderr.
- Changed two codes on the daemon's socket: a reply that cannot be read is
  EBADMSG, and a refused sessionDispatch is EREFUSED.
- Changed the health check's execution census to count one hooked domain
  fewer: the language-server hook that nothing called is gone.
- Changed how the Computer tool is described and counted: conditional on a

- Changed how Mercury reads the output of a host setup command (ssh-keygen,
