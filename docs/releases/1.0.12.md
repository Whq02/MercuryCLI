# 1.0.12 — queued

**State:** queued behind 1.0.11.

## What changed

- Added GPT-6.2 Astra and GPT-6.2 Sol to the model picker with their windows,
  output ceilings and prices from OpenAI's pages of 17 November: Astra at $8 a
  million input tokens, $40 output, $0.40 cached and $10 cache write, Sol at
  $2, $10, $0.10 and $2.50; a request over 272,000 input tokens at twice the
  input and cache rates and one and a half times the output rate. With an
  OpenAI API key Mercury offers effort low to max on both and sends medium
  when none is chosen; a ChatGPT sign-in's own list decides its levels. An
  unlisted model had run on a 200,000-token fallback and its usage went
  unpriced. Both are also on OpenCode Zen and in the head rows of the Nous
  Portal list.
- Added a debug-log line on the OpenAI road that lists the input items the
  provider reports it withheld from a request, by type, with the reason for
  each.
- Added GNU bash to what a macOS or Linux archive carries, under the GNU
  General Public License, version 3 or later: Mercury starts it as a separate
  program, and its licence text and a note naming its source ride beside the
  binary at `vendor/bash/<platform>/`.
- Changed the model a new session starts on after an OpenAI sign-in: the Sol
  of the newest GPT release the account serves, so GPT-6.2 Sol where it
  serves it and GPT-6.1 Sol, as before, where it serves neither 6.2 model.
  Where the account serves a release and not its Sol the session starts on
  that release's first model in Mercury's list, GPT-6.2 Astra where it serves
  Astra and not Sol, and on the account's own first model only where it
  serves none Mercury knows. Astra is in the picker beside the default.
- Changed the head rows of the Nous Portal list: GPT-6.2 Astra and GPT-6.2
  Sol take the place of GPT-6.1 Sol.
- Changed the OpenAI lines of /caching to today's facts: a 30-minute lifetime
  by default with 12 hours on offer and not asked for, and cached input at
  0.05 times the uncached rate on GPT-6.1 and GPT-6.2.
- Changed when a session compacts on GPT-5.6 Sol, Terra and Luna, GPT-6
  Astra, Sol and Luna, and GPT-6.1 Sol and Terra with an OpenAI API key, on
  OpenCode Zen and on the Nous Portal: at 879,000 tokens, before the
  922,000-token input maximum OpenAI's pages state, where it compacted at
  1,007,000; the two GPT-6.2 models compact there too. A window that a
  ChatGPT sign-in's list or your own settings state decides as before.
- Changed what the context gauge shows on those models: it names the
  1,050,000-token window as before, and the share left until compaction is a
  share of that window, 36% at 500,000 tokens where it read 48%.
- Changed the shell the Bash tool runs on macOS and Linux: Mercury ships GNU
  bash 5.3.20 and runs every command in it, whatever your login shell is. On a
  Mac whose login shell is zsh the model's bash commands had run in zsh. When
  the shipped bash cannot start, the system's own bash runs the command, and
  with no bash at all the bundled engine does; zsh is never run.
- Changed what a command starts from on macOS and Linux: the environment
  Mercury was started with, PATH and every exported variable, reaches each
  command as before, from a terminal, the daemon or an editor, and so do the
  aliases, functions and options of your bash files (`~/.bash_profile` or
  `~/.profile`, and `~/.bashrc`). Aliases and functions written in `~/.zshrc`
  no longer reach a command, and a variable set in `~/.zshenv` reaches one only
  when the program that started Mercury already had it: put what a command
  needs in `~/.bashrc`, or export it in the shell that starts Mercury.
- Changed the session's shell line on macOS and Linux to name the shell that
  runs and its version, where it named your login shell; on a system bash
  older than 4.0 the line also says how to hand over a message of several
  lines.
- Changed three questions the Bash tool asked before running a command: a
  command that holds `~[`, a word that begins with `=`, or the name of a zsh
  module builtin such as `zmodload` is read like any other, since bash gives
  none of them a meaning of its own.
- Fixed the effort dial on GPT-6 Astra, Sol and Luna and GPT-5.6 Sol, Terra
  and Luna with an OpenAI API key: the level chosen is sent, and medium when
  none is chosen, where nothing was sent and the provider's default ran.
- Fixed the cost shown for OpenCode Zen models with a long-context tier: a
  cache write past the threshold is priced at the long-context rate ($25 a
  million on GPT 6 Astra where it read $12.50), and a request of exactly
  272,000 tokens (200,000 on Grok) at the short rate.
- Fixed the cost shown for Nous Portal models whose list states a
  long-context price: a request at or above the list's threshold is priced
  at the list's long-context rates, where every size read the short ones
  (GPT-6.2 Astra from 272,000 input tokens: $16 a million input, $60 output,
  $0.80 cached and $20 cache write, where it read $8, $40, $0.40 and $10).
