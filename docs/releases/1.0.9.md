# 1.0.9 — published 2026-11-10

**State:** published 2026-11-10 at
github.com/Whq02/MercuryCLI/releases/tag/v1.0.9, tag on commit 9f4bb01f. A
stability release. The screen repaints whole and in place, a reply that was
cut no longer leaves a wrong conversation behind, a run that finished resumes
as finished, a rental creates the machine that was picked, and Claude Fable
5.2 is a declared model.

## What changed

- Added Claude Fable 5.2 and its Mythos 5.2 mirror as declared models.
- Added a Session scratchpads row to mercury health, with a fix that clears
  them.
- Added the reason to a session row that needs you on a narrow list.
- Added the untrusted-source line and the server's description to an MCP
  tool's permission card in a hosted session.
- Changed repainting: the frame is rewritten in place after focus, a resize,
  ctrl+l and any recovery, with no blank screen in between.
- Changed engine.roster to bind every way a model can be chosen.
- Changed TensorFold to 1.2.5.
- Changed local Qwen serving: a Modelfile's num_ctx is honoured and only the
  effort words the template accepts are sent.
- Changed every default-on switch to turn off on 0, false, no and off;
  MERCURY_WIN32_UTF8 still reads 0 only.
- Changed the configuration surface: MERCURY_GROUP_COMMIT,
  MERCURY_COMPACT_LADDER, MERCURY_EMBEDDED_SEARCH_TOOLS,
  MERCURY_RENDER_ENGINE, MERCURY_ENGINE_ASSERT and MERCURY_DEV_SURFACES with
  /showcase are gone.
- Changed Claude Fable 5 and Mythos 5 to use their 1M window by their plain
  id.
- Changed the Computer tool: a gone wait is met when the text leaves, a page
  that is still starting is waited for, and an incomplete tree says so.
- Changed the Computer tool's words: the page-content note, the skipped-step
  and interrupt lines, and a scale on every capture line.
- Changed the crew board so that one name belongs to one crewmate; main and
  all are reserved.
- Changed the /model picker: no group spends a line on one hidden row, and a
  narrow window keeps the context cell whole.
- Changed the contract card to stand whole on a short board.
- Changed the status band to give up its row under a tall card.
- Changed the hosted-machine pause to keep the vendor's state and to name
  Resume only where it works.
- Changed health and readiness rows to name the word that turned a flag off.
- Changed /config's local window note to say what auto is.
- Changed update and install to list the older versions still in use.
- Fixed a crew lead not being woken after a wake turn died.
- Fixed a reply whose stream closed without its end being recorded as
  finished.
- Fixed a withdrawn reply staying in the conversation and being sent again.
- Fixed a resumed session dropping a tool call that had no result.
- Fixed an endpoint id saved without a vendor mark hanging the model picker.
- Fixed a roster of an older Fable generation defaulting to Opus.
- Fixed a file's name being able to run a command through the external editor.
- Fixed the Computer tool refusing a row numbered by an app-scope read.
- Fixed /imagesetup's test image not naming its source.
- Fixed one damaged host notice hiding the valid ones.
- Fixed the update prune removing a version still in use.
- Fixed sessions leaving empty temp folders behind.
- Fixed the crew board losing the race to open a fresh board.
- Fixed the effort popup's width, the status band tearing under a popup, and a
  wrapped line losing its gutter.
- Fixed the transcript going blank after a tool group collapsed or a row
  changed its height.
- Fixed a click between two words not reaching its row.
- Fixed Enter on a group under the message cursor opening it out of view.
- Fixed a pasted text or image being lost when sent while the session was
  starting.
- Fixed keys being lost after the external editor closed on Windows.
- Fixed the arrow keys scrolling instead of moving the message cursor on
  Windows.
- Fixed a rental creating a different GPU shape than the one picked.
- Fixed a TensorFold rental attaching an old disk and stalling while billing.
- Fixed Vast.ai weights disks failing to list.
- Fixed the TensorFold wired-limit command naming the wrong number.
- Fixed a finished mercury run resuming as crashed, and a tool result missing
  from the record after a hard stop.
- Fixed an agent chosen with --agent starting without its prompt.
- Fixed a session's title, agent, tag and mode being lost from a large record.
- Fixed a permission card shown twice after a cut reply.
- Fixed /compact using the wrong context window after a model switch.
- Fixed a bundled skill's reference files not being restored.
- Fixed an ACP client being sent a withdrawn reply on load.
- Fixed a question card covering the conversation's last row on a small
  screen.
- Fixed a declined question reading as an error.
- Fixed the line count of a running command reading one over.
- Fixed a paused crewmate not resuming after its launching turn was
  interrupted.
- Fixed crewmates ending their turn early when their context neared full.
- Fixed an --ephemeral run saying its transcript was intact.
