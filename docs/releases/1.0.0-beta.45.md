# 1.0.0-beta.45 — ready for the tag

**State:** ready for the tag. A feature and reliability release. Mercury adds
the bundled `mercury-media` extension (`ext:mercury-media`) and `/imagesetup`
for local image and video generation on Apple Silicon macOS through
`stable-diffusion.cpp` (`docs/MEDIA.md`), adds direct Hugging Face GGUF
downloads and Bank serving to `/localsetup` (`docs/LOCAL-SETUP.md`), adds an
"Anthropic API key — usage-based billing" paste option and workspace ID
support under `/logins` → Anthropic, adds `ctrl+s s` to send a queued line into
a waiting turn at once, and adds twenty desert thinking verbs to the turn
spinner. The TypeScript and Python SDKs (`mercury-cli-sdk`) add
connection and whole-turn prompt timeouts, `MercuryConnectionError`,
`MercuryWireError` and `MercuryOutcomeError`, `mcp__mercury__lease_release`
adds `paths: null`, `agentId` and `all: true` and releases a crewmate's file
leases when the crewmate ends, `Write` and whole-file `Read(ranges)` return
file anchors while tool rosters and signed thinking stay intact across restarts,
MCP `list_changed` refreshes and compactions, and fixes land for Anthropic
Console sign-in and credential switching, malformed tool-call error results,
queued crewmate messages, Gemini stop reasons, stopped-crewmate resume on
Anthropic, Crewmates popup mouse handling, `Bash` working-directory
normalisation, advisor truncation markers, HTTP/2 connection blips under
crewmate fan-out, and the first-run wizard's trust step.

## What changed

- Added the bundled mercury-media extension and /imagesetup for local image and
  video generation on Apple Silicon macOS through stable-diffusion.cpp: enable
  Local media (media.enabled) in /config and open /imagesetup to inspect your
  media folder (media.root, ~/.mercury/media by default), memory and free disk
  space, download the 37.6 MB stable-diffusion.cpp runtime and any of the six
  catalogue models (z-image-turbo, flux2-klein-4b, qwen-image-21-turbo,
  qwen-image-21, wan22-ti2v-5b and minimax-h3-fl2va) with p through a consented
  SHA-256-verified pull card that supports Esc pause and p resume and counts
  shared encoder, vision projection and VAE files once, set the default image
  and video slots in <media.root>/config.json with d (or the Default image
  model and Default video model pickers in /config), preview a 256×256 test
  image inline with t, and drive local generation through seven MCP tools
  (media_models, media_status, media_set_default, image_generate,
  video_generate, media_jobs and media_result) with Local image and Local video
  permission cards and a Local media row in /health (docs/MEDIA.md)
- Added direct Hugging Face GGUF downloads and Bank serving to /localsetup:
  choose Hugging Face (or run /localsetup <author/model-GGUF>) to list each
  complete GGUF quantisation in a repository with its download size and whether
  it fits your computer's memory at the largest fitting 32k, 64k, 128k or 256k
  context window calculated from the GGUF header's attention geometry and any
  mmproj vision projector, pull the chosen quantisation and projector into the
  Bank with SHA-256 verification and resumable downloads (or choose Bank to
  start a GGUF already in the Bank without re-downloading), launch llama-server
  on 127.0.0.1:8080 as the local-gguf project service (passing --spec-type
  draft-mtp when the model carries NextN/MTP tensors) and select local/<name>,
  while Esc stops only the server the dialog started (docs/LOCAL-SETUP.md)
- Added "Anthropic API key — usage-based billing" to /logins → Anthropic
  alongside "Claude subscription — browser sign-in" and "Anthropic Console —
  browser sign-in" on the in-chat card and the boot screen: paste a masked
  Anthropic API key, verify it against /v1/models?limit=1 before saving
  (prompting for the workspace ID from Console → Settings → Workspaces when the
  key is organisation-scoped and sending anthropic-workspace-id on Messages,
  token-counting and model-catalogue requests), and report any refusal in place
  without storing a rejected key
- Added ctrl+s s (ctrl held, s pressed twice within two seconds) to send a line
  queued behind a running turn into that turn at once while it waits inside a
  tool call: a crewmate or shell command the turn was waiting on moves to the
  background and keeps running (its result arrives as a notification), a Sleep
  ends, and the status row shows ctrl+s s sends now only while the chord is
  live; the SDKs gain sendNow() and send_now() on the session (docs/SESSIONS.md)
- Added twenty thinking verbs to the turn spinner's desert set
- Changed the TypeScript and Python SDKs (mercury-cli-sdk in sdk/ and sdk-py/):
  connect({ timeoutMs }) and connect(timeout=seconds) bound runner
  initialization, prompt() timeouts bound the whole turn including queue
  acceptance (with interruptOnAbort: true and interrupt_on_cancel=True to
  interrupt on timeout), broken streams and calls during or after close()
  (including on SyncSession) raise MercuryConnectionError instead of hanging,
  malformed known notifications raise MercuryWireError, and assertCompleted and
  assert_completed raise MercuryOutcomeError carrying outcome, errorClass or
  error_class, detail and the runner's recovery instructions (sdk/README.md,
  sdk-py/README.md)
- Changed project file leases on the in-process mercury MCP server:
  mcp__mercury__lease_release accepts paths: null (or omitted) to release every
  lease the caller holds, accepts agentId or all: true from the main session to
  release one crewmate's or every holder's leases in its own session (never
  another session's), and releases a crewmate's file leases when the crewmate
  finishes, fails or is stopped without clearing leases taken after a resume
  (docs/CREW.md)
- Changed Write, Read(ranges) and ChangeSet anchor handling and tool-schema
  updates across restarts, MCP refreshes and compactions: Write and whole-file
  Read(ranges) return a (anchor: fa:…) file anchor for Edit and ChangeSet, and
  stale-anchor refusals name the Read call that refreshes the file instead of
  printing the current anchor value; restarting or resuming a session onto a
  new Mercury build replays the recorded tool roster so the prompt cache prefix
  and signed thinking stay intact; MCP tool changes from
  notifications/tools/list_changed or /mcp reconnect update unreferenced
  deferred tools in place and send a tool_schema_delta attachment for
  already-referenced tools without moving the bound prefix; and context
  compaction carries tools loaded in full across every provider
  (docs/CHANGE-TRANSACTIONS.md)
- Changed internal modules across services, tools, components, commands,
  extensions and utilities to remove unused helpers, duplicate classifiers and
  dead declarations with no change to behaviour or screen text
- Changed local media setup so that a successful pull in /imagesetup turns Local
  media on and connects the engine in the running session (a declined, failed,
  paused or runtime-only pull leaves it off), a model installed or set as
  default mid-session is used by the next call without a reconnect, and
  image_generate and video_generate take the slot default when no model is named
  and a named model for that call only (docs/MEDIA.md)
- Changed the bundled provider-apis skill to describe the current provider APIs as Mercury uses them
  (the HTTP/1.1 transport, the three Anthropic sign-in options and the workspace
  header, tool-call gating, the Gemini signature order, tool-roster replay),
  each vendor page checked on 2026-10-26
- Fixed Anthropic Console sign-in, stored API-key refresh, and in-flight
  account switching: Console sign-in awaits key storage before finishing, never
  reuses a closed OAuth flow, and does not overwrite your Claude subscription
  account record; warm processes re-read a replaced stored API key from disk
  instead of keeping the previous key in memory; explicit API-key checks never
  borrow a subscription bearer token or oauth beta header; and switching
  Anthropic account slots applies to new requests while a turn or crewmate in
  flight keeps the credential it started with and re-resolves on HTTP 401
- Fixed malformed tool-call results, queued crewmate messages, Gemini stop
  reasons, stopped-crewmate resume on Anthropic, and API request deadlines:
  tool calls whose arguments fail schema validation, are not a JSON object, or
  name an unknown tool return a paired tool_use and error tool_result across
  OpenAI, Z.AI, Gemini and OpenAI-compatible streams (while unpairable calls or
  Gemini MALFORMED_FUNCTION_CALL responses return a refused result and
  correction notice); a crewmate with messages queued while it was working
  starts its next turn before settling as completed; Gemini replies whose
  thought signature arrives after the answer text keep the text block and
  end_turn stop reason; resuming a stopped crewmate on Anthropic merges
  consecutive user messages and bounds response body reads to the request
  timeout so TaskStop followed by ResumeCrewmate does not hang; and hanging
  loopback connections count against the API retry budget (docs/AUTOMATION.md)
- Fixed mouse and page-key handling in the Crewmates popup: while the Crewmates
  list is open, the mouse wheel and PgUp/PgDn scroll the list instead of the
  chat transcript behind it, clicking a row selects it, and clicking the
  selected row again or double-clicking any row opens it like Enter
- Fixed Bash working-directory normalisation and piped verification command
  scoring: Bash strips a leading cd <dir> && prefix only when it matches the
  persistent shell's current working directory (or the call's cwd) instead of
  the session root and preserves the cwd parameter on every call, and
  verification command scoring ignores status-printing commands, wait, and
  read-only diagnostics (grep, rg, head, tail, sed, awk, wc, cut, sort, uniq,
  diff, cmp) while still flagging piped test commands whose exit status is not
  captured
- Fixed advisor input and result truncation and crewmate launch receipts: the
  advisor keeps every key of a tool call's input when shortening long strings,
  reads tool results up to the digest budget, marks any truncated input or
  result and suppresses notes that depend on unseen text past a truncation
  marker, and crewmate launch receipts name the resolved model across all
  providers including Anthropic
- Fixed Connection error [ERR_HTTP2_STREAM_ERROR] blips under crewmate fan-out
  and long Gemini streams: every API dispatcher (direct, proxy and mTLS) uses
  HTTP/1.1 with sixteen connections per origin instead of one shared HTTP/2
  session, so one refused stream, reset or GOAWAY no longer cuts the other live
  streams
- Fixed the local media model downloader running on the session's environment
  (it now runs on the scrubbed subprocess environment, never the session's
  secrets) and a letter typed with Ctrl or Alt held triggering /imagesetup
  actions
- Fixed an advisor note that arrived as /advise off landed being discarded: the
  note is kept and delivered when the advisor is next on
- Fixed the resumed-session card painting inside the previous turn instead of
  after its summary line, the first-run wizard's trust step showing two key-hint
  rows instead of one, and Esc at the trust step ending setup without a word: it
  now says "Setup stopped. Run mercury again to finish."
