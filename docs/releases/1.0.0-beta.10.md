# 1.0.0-beta.10 — at the gate

**State:** release candidate. The four items below are on the release line;
the hosted gate and the local pool run on it; the verdict, the tag commit and
the publish line are written at the tag. What did not make this tag is on
[1.0.0-beta.11.md](1.0.0-beta.11.md).

1. **The OpenAI route's tool calls** — empty placeholders stripped at the
   decode for every tool, the quote normalisation, an Edit refusal naming the
   read lines.
2. **A bundled bash** — a Windows box with no bash gets one in the archive, so
   the shell tool works the same everywhere.
3. **Colours within the terminal's reach** — Fixed the first-run screen and
   the mascot painting wrong colours in Apple's Terminal and other 256-colour
   terminals: a terminal that advertises no 24-bit colour is painted in the
   256 colours it has, the enter screen included; `MERCURY_TRUECOLOR=1`
   forces the full depth, `=0` clamps it, and the doctor's Terminal color row
   names the depth and why.
4. **The provider gate's remainder** — the delegation latches, and an expired
   sign-in reported as what it is, never as an exhausted usage window. Fixed
   delegated agents refused long after a usage window reset, and an expired
   sign-in reported as a used-up window: the verdict lapses at the reset it
   names and the refusal says when; a 401 or an invalid grant never sets it,
   and is answered with the sign-in line and `/logins anthropic`.

**Still queued, not this tag:** [1.0.0-beta.11.md](1.0.0-beta.11.md).
