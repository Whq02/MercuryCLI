**What shipped (the bundled changelog is the one source; `mercury /release-notes` prints it):** the GPT route's tool calls arrive clean; a bundled bash-compatible shell in the Windows archive; delegated agents no longer refused after a usage window reset, and an expired sign-in named as such; 256 colours where the terminal has no more; a sign-in reaching an open chat's account facts at once.

**Ships in this tag**

1. **The OpenAI route's tool calls** — empty placeholders stripped at the
   decode for every tool, the quote normalisation, an Edit refusal naming the
   read lines.
2. **A bundled shell for Windows** — the Windows archive carries Mercury's
   own bash-compatible engine (brush 0.4.0) by contract, and a box with no
   bash runs the shell tool through it with no setting; a box with bash keeps
   bash, and macOS and Linux are unchanged. This is not GNU bash: bash 5 with
   a coreutils pack is the first item of 1.0.0-beta.11.
3. **Colours within the terminal's reach** — Fixed the first-run screen and
   the mascot painting wrong colours in Apple's Terminal and other 256-colour
   terminals: a terminal that advertises no 24-bit colour is painted in the
   256 colours it has, the enter screen included; `MERCURY_TRUECOLOR=1`
   forces the full depth, `=0` clamps it, and the doctor's Terminal color row
   names the depth and why.
4. **The provider gate's remainder** — the delegation latches, and an expired
   sign-in reported as what it is, never as an exhausted usage window. Fixed
   delegated agents refused long after a usage window reset, and an expired
   sign-in reported as a used-up window: the verdict lapses at the reset it
   names and the refusal says when; a 401 or an invalid grant never sets it,
   and is answered with the sign-in line and `/logins anthropic`.

5. **A sign-in reaches an open chat's account facts at once.** The engine
   behind an open chat read its account from a cache refreshed by a file poll
   and re-sent its facts only on the next frame, so a sign-in mid-turn showed
   the old account until the next message; on the daemon's nudge it now reads
   its config again and answers its facts right after.

**Known gaps in this tag**

- The bundled shell is the shell alone: a script that calls `grep`, `sed` or
  `awk` on a Windows box without them still fails, and background or
  streaming shell calls still take the old path on a box with no bash.
- A terminal Mercury cannot recognise, most SSH sessions among them, is
  painted in 256 colours unless `MERCURY_TRUECOLOR=1` is set.
