# MERCURY.md
Standing orders for the Mercury harness in this repository.

- The operator's word names the model for every lane, seat and review. No model is paired with a kind of work by default and none is off limits; a project file never outranks what the operator says, and a conflict between the two is asked, never settled alone.
- A minor look change (a row's words, a count, a clamp clause, a notice) lands on its source-render frames without the owner's approval; only a big design change — the outline, the format, the design orientation, animation or rendering presentation — stops at frames for the owner before it lands.
