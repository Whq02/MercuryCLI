## Preserved NOTICE files (Apache-2.0 §4(d))

The preservation sweep walked every installed package root (transitive dependencies included) for `NOTICE`/`NOTICE.txt`/`NOTICE.md` files and found **none** in the current dependency set — the Apache-2.0 packages above ship a LICENSE file only.
